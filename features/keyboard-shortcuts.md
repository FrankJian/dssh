# 应用快捷键

设置 → 快捷键可查看和修改全部 26 项绑定，按「全局 / 工作区 / 分屏 / 终端」分组。下表列出新增操作；主修饰键在 macOS 为 ⌘，Windows/Linux 为 Ctrl，Alt 在 macOS 对应 ⌥。

| 操作 | 默认组合（主修饰键 +） |
| --- | --- |
| 打开设置 | , |
| 新建本地终端 | Shift + T |
| 新建 SSH 连接 | Shift + N |
| 打开连接管理 | Shift + M |
| 显示 / 隐藏侧栏 | Shift + B |
| 显示 / 隐藏 AI 助手 | Shift + A |
| 进入 / 退出禅模式 | Shift + Z |
| 聚焦当前终端 | Shift + J |
| 左右分屏 | Shift + E |
| 上下分屏 | Shift + O |
| 上一个 / 下一个面板 | Alt + ← / → |
| 上一个 / 下一个标签 | Alt + ↑ / ↓ |
| 关闭当前面板 | Shift + X |
| 关闭当前标签 | Shift + W |

分屏基于当前聚焦面板，复用现有同主机连接流程；关闭面板只关闭一个终端，关闭标签则关闭整棵分屏树。运行中的任务仍走原有关闭确认流程。面板切换按布局树顺序循环，键盘输入焦点同步移动；终端全屏时切换到目标面板并保持全屏。标签切换遵循拖拽后的排列顺序，包含终端与 SFTP。

分屏和关闭面板仅在终端视图生效；标签关闭不会截获文件编辑器的关闭操作。锁屏、弹窗、快捷键录制及下拉菜单期间不执行新增操作，输入法组字与长按重复事件也不触发操作。文件编辑器保留自身按键；普通输入框内仅允许设置、侧栏、助手与返回终端等带主修饰键的导航操作。原有 Ctrl+C、Ctrl+D 等 shell 按键默认保持原行为。

独立终端窗口支持分屏、面板切换、返回终端焦点、关闭面板和关闭标签；独立 SFTP 窗口支持关闭标签。新建终端、设置、连接管理、AI 助手、侧栏和标签切换等主窗口操作不会跨窗口执行。

按钮提示和命令面板中的相关操作显示当前绑定。新旧配置使用同一个本机存储键，已有自定义绑定保留；新增操作使用默认绑定。自定义绑定优先于默认绑定，不会被新增加的默认值抢占；如存在重合，可在设置中重新分配。

验证：`pnpm test:shortcuts` 在独立 macOS / Windows 平台环境验证默认绑定无冲突、自定义与重置、应用按键交接、输入法 / 长按 / 弹窗 / 编辑场景及循环顺序。浏览器隔离预览使用实际 xterm、PaneGrid 与统一分发 hook 验证左右 / 上下分屏、焦点切换、按键未写入 shell、输入框与弹窗阻止执行。浏览器自身保留的组合键用仅作用于预览的临时绑定验证，不改动用户配置。Windows 与原生独立窗口实际键盘验收仍待完成。
