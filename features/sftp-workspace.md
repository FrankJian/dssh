# SFTP 双栏工作台

保持服务器在左、本机在右，沿用 Graphite Glass 语义主题，文件区不使用模糊背景。

## 文件浏览与操作

- 详情列表显示名称、大小及修改时间，点击列头切换升 / 降序；目录始终在前，名称使用自然数字排序。窄窗口自动省略修改时间。
- 两侧各自保留当前挂载期间的导航历史和排序；提供前进 / 后退、上级、主目录、可编辑路径与本机常用位置。隐藏文件默认隐藏，眼睛按钮同步切换两侧显示。
- 筛选框旁提供两栏独立的“递归搜索”选项：默认只筛选当前目录；开启后，对当前目录及子目录的文件名 / 相对路径做不区分大小写的模糊匹配，例如 `cfg json` 可匹配 `app/config.production.json`。结果显示相对路径，可从右键菜单打开所在目录。Ctrl / ⌘ 点击多选，Shift 连选，Ctrl / ⌘ A 只选择当前可见项目；筛选隐藏的项目会从选择中移除。
- 递归搜索在输入停止 300ms 后开始，逐步显示结果和扫描目录数，可停止或重新搜索。切换目录、查询词或隐藏文件设置会取消旧搜索，旧响应不再更新界面。停止后不再请求新目录，已经发出的目录读取请求返回时会被忽略。搜索不跟随符号链接目录；默认跳过隐藏文件及隐藏目录，权限不足的目录单独统计并继续搜索其余目录。
- 单次搜索上限为 2,000 个目录、100,000 个项目和 2,000 条匹配结果，达到任一限制会明确提示缩小范围。递归匹配通过现有 Rust 目录接口读取，不使用远端 shell 命令，也不搜索文件内容。
- ↑ / ↓、Home / End 浏览列表；Ctrl / ⌘ L 聚焦路径，Ctrl / ⌘ F 聚焦筛选，Alt+↑ 返回上级，F5 刷新，F2 重命名，Delete 打开删除确认，Esc 清除选择。
- 工具栏和文件右键菜单提供传输、重命名、复制路径、删除。菜单点击不因 WebKit 的空失焦目标而提前关闭；点击外部、焦点移到外部、窗口失焦或调整尺寸会关闭菜单，支持 ↑ / ↓、Home / End 选择可用菜单项和 Esc 返回原文件。新建文件和目录在各自栏顶部。删除会永久移除内容，必须通过应用内对话框确认。
- 双击目录进入，双击文件复用 Monaco 编辑器及已有文本 / Markdown / 图片预览能力；编辑器按钮返回文件列表。两侧编辑器独立保留未保存内容，返回列表可再次进入。编辑中的项目及其父目录需先保存并关闭编辑标签才能重命名 / 删除。多个编辑器实例使用独立 Monaco 模型标识。

## 地址栏与 Windows 路径

- 地址栏草稿与实际浏览目录分开：只有后端成功返回的规范路径会更新列表和标签路径；失败时恢复已确认路径，保留请求期间新输入的草稿。地址栏内按 Esc 可恢复当前实际目录。
- 本机地址支持完整盘符、正斜杠输入、UNC 共享、Explorer“复制文件地址”的外围引号、`file://` URL、`~` 主目录及相对当前面板的 `..` / 子目录。`C:` 明确进入 `C:\`；拒绝依赖进程工作目录的 `C:folder` 写法。环境变量不自动展开。
- “上一级”不会越过盘符根目录或 `\\server\share` 共享根目录，也不会将 POSIX 文件名中的反斜杠误当作分隔符。Windows 普通盘符 / UNC 的规范路径前缀可友好显示，Volume GUID 等特殊路径保留有效前缀。
- 远端路径始终由 SFTP 服务器规范化，不随客户端 Windows 系统改为反斜杠；保留 Windows SFTP 服务器的 `C:/` / `/C:/` 盘符根形式。相对路径从当前远端目录解析。
- 文件接口保留真实路径里的有效空格，避免指向另一个条目；Windows 下载名称不能包含路径分隔符、ADS 冒号、保留设备名或会被系统消除的尾部点 / 空格。同批次及目标冲突在 Windows 下载时按大小写不敏感检查。本机新建文件使用独占创建，避免同名文件被截断。

## 传输行为

- 下载默认进入右侧当前目录；“下载到…”保留原生目录选择器。上传目标为左侧当前目录。
- 将选中文件拖到另一侧文件列表传输，不在同一侧隐式移动文件。双栏内部使用指针捕获与坐标命中检测，不依赖 HTML5 `dragstart` / `drop`；保留 Tauri 原生外部文件拖放。移动超过 5px 才开始拖拽，显示文件 / 数量预览与目标栏高亮；同栏 / 栏外松开、Esc、指针取消及窗口失焦不会发起传输。原生与 HTML5 拖放的 Windows 限制见 [Tauri 配置文档](https://v2.tauri.app/reference/config/#dragdropenabled)。
- 从 Finder / Explorer 拖到左侧服务器栏，可上传本机其他位置的文件和文件夹。Tauri 原生事件提供路径，通过 Rust 目录接口读取元信息并识别文件 / 文件夹，文件夹走递归上传。目标为左侧当前目录；物理坐标按窗口尺寸换算为 WebView 坐标，处理 Retina / DPI / 缩放。隐藏标签、编辑器或对话框覆盖、本机栏投放均不会触发上传。重复路径和目录内嵌选择会去重；同一批次不同来源的同名项目要求分批上传，避免互相覆盖。
- 开始前重新读取目标目录，遇同名顶层项目时选择覆盖、跳过或取消。覆盖合并目录并替换目录内同名文件；跳过会跳过整个同名顶层项目。
- 本批次任务串行执行，底部可展开查看等待、传输、完成、失败或取消状态。单项失败继续处理其余项；保留失败原因，进度和取消继续复用后端 operation ID。
- 可以在传输时继续浏览目录，完成时只刷新仍停留在原目标且未发起其他导航的面板。新建 / 重命名 / 删除及新传输在当前批次执行时禁用。
- SSH 认证、连接池、主机密钥校验、递归传输与取消机制沿用既有 Rust 服务；没有新增凭据访问路径。

## 当前边界与验收

传输列表是当前批次状态，不是持久化的后台调度器；不提供暂停、断点续传、追加队列、失败重试、目录同步或目录收藏。搜索结果中的文件按真实路径打开、重命名和删除；传输到目标当前目录时，若所选不同来源文件同名，需分批传输。选择目录及其子项目时只处理目录一次。关闭标签 / 窗口期间的传输生命周期沿用现有实现。文件内容编辑仍遵循既有大小、格式与保存限制，不新增外部变化合并或文件锁。

自动回归：`pnpm test:sftp`，验证自然排序、目录优先、过滤后范围选择、缺失时间戳与历史分支 / 有界缓存。前端执行 `pnpm exec tsc --noEmit` 和 `pnpm build`。

界面使用模拟 Tauri IPC 做隔离浏览器检查；真实 SSH 大目录 / 大文件、取消 / 中断、目录冲突、符号链接、原生 WebView 拖拽、macOS / Windows 路径和多窗口编辑需要进一步验收。

右键菜单回归使用模拟文件并强制在菜单按钮 mousedown 时先触发 blur：旧逻辑会关闭菜单且不执行回调；修复后打开、下载、重命名、复制路径、删除确认回调均可执行，并验证多选保留、跳过禁用菜单项、Enter 执行、Esc 焦点恢复和点击外部关闭。测试不执行实际文件删除或传输。

双栏拖拽回归：在禁用 HTML5 dragstart 的隔离测试页中验证本机 → 服务器上传、服务器 → 本机下载、多选批次、同名确认 / 跳过、同栏松开不发起任务。纯状态回归覆盖拖动阈值、指针归属、合法目标和传输路径快照。测试使用模拟 IPC；真实原生窗口与真实 SSH 仍需验收。

外部拖入回归：通过 Tauri 公共事件接口模拟 enter / drop / leave，以 2× DPI 验证外部文件、目录递归、同名确认 / 取消、本机栏忽略及后台标签不重复上传。纯函数覆盖 DPI 换算、macOS / Windows / UNC 路径、元信息读取、嵌套选择去重和同名来源拦截。已用隔离标识启动 macOS 原生开发窗口并检查；当前自动化无法完成跨应用拖拽，真实 Finder 手势及 Windows Explorer 投放仍待实机验收。

坐标兼容：当前依赖 Wry 0.55.1 的 WKWebView 实际返回 Cocoa 逻辑点，Tauri 仍将其包装为 `PhysicalPosition`；Windows 返回物理像素。macOS 先使用原生窗口 `scaleFactor()` 转成物理坐标，再统一换算到 CSS 像素，避免 Retina 上重复缩小。双栏和远程文件树共用换算函数；回归覆盖带侧栏偏移的左边缘、中央、右边缘，以及本机栏不能误命中服务器栏。升级 Wry 时须重新核对该平台差异。

递归搜索回归：覆盖模糊 / Unicode / 多关键词匹配、隐藏目录、符号链接、权限失败、取消后忽略响应、扫描上限、Windows / UNC 相对路径及父子选择去重。模拟 IPC 页面验证两栏独立搜索、关闭递归恢复目录筛选、等待输入时停止搜索，以及子目录文件重命名不改变其所在目录。真实 SSH 超大目录、网络超时和原生多窗口搜索仍需验收。
