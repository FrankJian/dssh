# AI 助手停靠布局

助手支持右侧、左侧和底部停靠，默认右侧。可在助手标题栏的布局图标菜单（展开后横向显示左 / 底 / 右图标，当前项高亮）、设置 → AI → 助手停靠位置、模型配置中的同名选项，或命令面板的“AI 助手停靠在…”动作切换。现有打开 / 关闭助手快捷键沿用保存的位置。

## 工作区布局

- 右侧：保留原有次级侧栏布局。
- 左侧：位于原有会话 / S3 侧栏与主工作区之间，导航栏和原有侧栏继续可用。
- 底部：只占主工作区下方，会话 / S3 侧栏仍贯穿左侧全高；顶部标签条与终端动作留在主列上方。
- 主机工具与助手继续共用同一个辅助面板，两者互斥；主机工具固定右侧，宽度单独保存。

布局通过同一 CSS Grid 的区域分配切换，助手和主列不因改变停靠位置而被移到另一个 DOM 父节点。聊天草稿、滚动位置、工具确认和终端内部状态可保留；终端既有 ResizeObserver 负责重新适配 PTY 尺寸。切换到主机工具、关闭助手等原有面板切换行为不在此项状态保留保证内。

## 尺寸与响应式

左右停靠共享记忆宽度（默认 360，范围 280–640px）；底部单独记忆高度（默认 320，范围 220–600px）。拖动分隔线调整，方向键每次调整 16px，Shift + 方向键每次 40px，Home / End 到最小 / 最大值，双击恢复默认。拖动结束、取消、窗口失焦及组件卸载时均清理监听和全局光标。

实际显示尺寸还受当前工作区约束：优先给主区保留约 320px 宽、200px 高；侧栏和辅助面板可临时收紧，不覆盖保存的偏好。更窄的窗口临时隐藏原侧栏，放宽后自动恢复，不改变用户的侧栏折叠设置。原生窗口最小尺寸仍为 960 × 640。

底部助手宽度达到 680px 时，聊天内容在左、输入区在右；更窄时采用上下布局。模型 / 推理菜单根据面板空间限制高度并滚动，避免底部或侧边裁切。深浅主题均使用现有 Graphite Glass 语义颜色。

位置保存于本机 `dssh.ai.dockPosition`，宽度沿用 `dssh.ai.panelWidth`，底部高度使用 `dssh.ai.panelHeight`，主机工具宽度使用 `dssh.hosttools.panelWidth`。旧配置无需迁移，默认位置仍是右侧。禅模式和终端全屏继续临时隐藏辅助面板，退出后按保存的位置恢复。

## 验证

`pnpm test:assistant-dock` 覆盖默认值、非法偏好、三方向 Grid 区域、底部侧栏全高、960px 起的尺寸约束、窄窗口恢复、关闭面板和无 chrome 布局。另运行双平台快捷键匹配回归、TypeScript 与生产构建。

使用真实 AppLayout / AiChat / 停靠设置组件的独立浏览器预览，模拟聊天和终端数据并隔离本地偏好：已核对三方向、深浅主题、960px / 720px 窄布局、键盘及指针拖动、模型长列表、设置联动、助手 / 主机工具切换，以及位置切换时草稿和终端输入状态保留。该预览不连接真实 SSH，不代表 macOS / Windows 原生 Tauri、真实分屏 / SFTP 的完整验收。
