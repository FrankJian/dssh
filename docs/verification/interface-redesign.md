## 本轮统一组件与重排进度

- 参考 Appica UI 的组合控件、Semi Design 的导航和内容层级，以及 21st.dev 的紧凑交互细节。页面共享语义颜色、线性图标、控制尺寸、焦点和禁用状态。
- 多选一且选项较少时使用 `SegmentedControl`，共享滑动选中背景和原生单选键盘行为。连接视图、SFTP 分组、工具箱筛选、应用主题和光标形状已接入。布尔配置使用 `SettingsSwitch`。
- 控件共享 32px / 28px 高度、圆角和间距。交互使用 120ms / 180ms 时长和统一缓动，页面验证须覆盖状态保留及焦点。
- 终端“输出历史”采用四段预设（不保留 / 2,000 行 / 10,000 行 / 自定义）、带单位的圆角数值输入和标题右侧恢复默认入口；不显示常驻小字说明，仅在出错时显示反馈。保留 0～100,000 行边界及本机 / 跨窗口设置模型。类型检查、生产构建、5 项存储 / xterm 回归及 macOS 原生宽浅色 / 窄深色检查通过；实机验证了预设、自定义 5,000 行、超限原位报错、Esc 撤销输入、不保留模式与恢复默认。
- 连接管理已重排为轻导航、筛选工具栏和圆角内容表面。首轮浏览器验证覆盖浅色宽布局、深色窄布局和分段切换。
- SFTP、S3 和 Artifactory 首轮重排已完成，共用 `WorkspaceToolbar`，S3 与 Artifactory 共用 `Breadcrumbs`。SFTP 保留可编辑路径与建议列表，双栏使用一致的标题高度、列表行高与间距。Artifactory 文件详情可关闭，窄内容区改为上下排列。
- 文件工作台的模拟浏览器检查覆盖三个模块的宽浅色 / 窄深色布局、路径导航与文件详情。SFTP 现有 35 项回归通过。真实连接与传输、跨窗口、自定义配色和键盘操作仍需完整验收。
- JumpServer 与主机工具首轮已接入共享工具栏。主机工具采用统一分段选择，刷新频率使用共享选择器。JumpServer 调整搜索、目录、资产与账号操作的层级，修正窄资产行操作重叠。
- AI 助手将输入框、模型、推理档位和发送操作整合到同一圆角表面，320px 侧栏中模型选择单独成行。底部停靠沿用消息与输入双栏，新增消息和分类切换过渡。
- 本轮模拟浏览器覆盖 AI 侧栏 / 底部停靠、主机工具分类切换、JumpServer 资产选择与授权账号呈现。真实 SSH 快照、模型流式对话与原生停靠仍需验收。
- 连接表单首轮统一了输入高度、焦点、圆角与底部操作。SSH 认证接入共享分段选择，图标、标签与描述按需展开；S3 按连接 / 访问凭据分组；RDP 与 JumpServer 的长表单保持底部操作可见，布尔选项使用共享开关。连接目录移除重复说明，保留格式示例。
- 连接弹窗与配置密码弹窗的隔离浏览器检查覆盖宽浅色、窄深色及 390px 内容区。SSH、S3、RDP、JumpServer、配置密码弹窗均验证 Tab 循环、Esc 关闭与焦点返回；锁屏密码弹窗接入同一焦点管理。尚未覆盖真实保存、原生文件选择、系统凭据及跨窗口交互。

- 焦点管理归并到 `src/ui/useDialogFocus.ts`，连接表单、设置、认证与确认弹窗复用。SSH / S3 删除、主机密钥、OTP、同名下载、S3 路径 / ACL / 清理及 Artifactory 属性弹窗已接入；删除 / 写入处理中禁用关闭，清理最终确认出现时隔离底层预览。修复共享 RDP 表单样式调整后临时连接与删除弹窗缺失内容边距的问题。新增主机密钥、SSH 删除、S3 ACL / 路径、属性弹窗已补做窄自定义深色初始渲染检查；完整操作与原生交互待验收。
- 端口转发使用共享分段选择，类型在地址前，按转发方向分别标识监听端与目标端；窄弹窗上下排列地址组。SOCKS5 隐藏远端字段，创建 / 关闭操作显示禁用状态。浏览器已验证动态转发参数及活动行呈现，真实 SSH 转发仍待验收。

- 文件属性、目录树删除和编辑器未保存确认复用原生 HTML `dialog` 组件，统一标题、正文、固定操作区和错误对齐；处理期间保持背景不可操作。菜单打开弹窗前先将焦点交还文件行，避免弹窗关闭后焦点丢失。隔离浏览器已覆盖属性 / ACL / 重命名 / 删除的菜单衔接，以及编辑器保存失败后的重试入口、取消与焦点恢复。

- 删除等不可逆操作统一使用 `Button` 的危险操作样式。深浅外观下正文及悬停文字对比度最低为 4.66；自动回归约束不低于 4.5。

- 更新提示复用共享 `Dialog` 标题和固定操作区，长更新记录单独滚动；安装期间隔离背景且禁止关闭，失败后可重试。560px 隔离浏览器验证了长记录、自定义深色外观、初始按钮焦点、模拟下载失败、取消和焦点返回；未执行真实下载或重启。共享弹窗支持显式指定初始焦点，不依赖隐藏弹窗内的 React `autoFocus`。
