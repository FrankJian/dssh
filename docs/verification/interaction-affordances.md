# 控件反馈与可执行菜单验证

2026-11-28；变更 `refine-interaction-affordances`。本轮覆盖应用共享控件、编辑器菜单、AI 操作菜单及动作工具栏。未改配置保存、动作授权和后端执行。

## 已验证

使用内置浏览器打开 `tests/interaction/`，运行真实 Button、IconButton、EditorActionMenu、AiToolbarMenu 和主题 CSS；不调用原生 IPC、不访问用户文件或远端。

- 普通按钮与图标按钮点击后真实处于 `:hover`：计算样式为 `cursor: pointer`，出现 `0 2px 6px`、12% 语义色的轻阴影，无 transform 或尺寸变化。
- 禁用表单按钮和图标仍可见，指针为 default、阴影为 none；工具栏及通用动作菜单中的禁用按钮为 `display: none`。disabled 属性保留，CSS 隐藏不代替执行保护。
- 动作列表最初只显示“文件 / 打开”，没有禁用“条件保存”和空“保存”分组，也不显示空菜单入口。切换可用性后“保存 / 条件保存”和工具栏动作恢复。
- ArrowDown 打开菜单并聚焦首个可用动作；Escape 关闭并恢复触发按钮焦点。
- AI 无会话动作时菜单只有模型配置，没有空分隔组。该组件的重命名、清空、删除根据原条件呈现。
- 文本输入为 text，尺寸分隔条为 col-resize，可拖动目标为 grab，编辑器树行和文件标签为 pointer。
- 观察浅色宽容器与深色紫色自定义配色下的 360px 窄容器：控件换行，菜单可读且未越过视口。此处是窄内容容器验证，不是原生窄窗口。

另使用 `tests/sidebar/?theme=light&reset` 挂载真实 App（模拟 IPC）：

- 空编辑器工具栏只显示可执行的文件、视图和工具菜单；文件菜单只有新建、打开文件和打开文件夹。
- 单工作区标签的右键菜单不显示关闭其他、关闭左侧、关闭右侧。新增第二个标签后恢复关闭其他和关闭左侧，仍隐藏没有右邻居的关闭右侧。
- 新建文本文件后文件菜单出现保存、另存为和全部保存；编辑器内容及已有工作区保持。工具栏中的禁用前进、后退和工作区搜索均不显示。

## 边界

原生 macOS/Windows 菜单、WebView、真实 SSH/SFTP 和独立窗口尚未实机复验。原生编辑器自定义动作通过发送前的模型过滤验证；操作系统管理的剪贴板、窗口菜单和第三方编辑器内部菜单仍由宿主管理。本轮没有重新验证系统减少透明度设置，轻阴影不新增模糊或玻璃层。

其他应用动作菜单共享语义隐藏规则，文件列表、设置 listbox 选项和表单输入不套用该规则；没有逐个连接所有远程服务验收。发布前仍需两平台原生鼠标、菜单和焦点复验。
