# 启动按需加载验证

2026-11-28，macOS 开发环境；基线为 `f554b0f`，本次变更为 `improve-startup-loading`。

## 生产构建依赖

相同依赖和 Vite 配置下，统计生产 HTML 入口及递归静态 `imports` 的 JavaScript UTF-8 字节；动态功能分块不计入首屏。gzip 为各分块压缩后的合计，用于可复现对比，不代表 Tauri 本地资源实际传输。

| 指标 | 修改前 | 修改后 | 减少 |
| --- | ---: | ---: | ---: |
| 首屏静态 JavaScript 字节 | 1,799,770 | 660,067 | 63.3% |
| gzip 字节 | 506,364 | 197,716 | 61.0% |

入口不再静态包含 xterm/WebGL、Monaco、编辑器工作台、设置、文件浏览器和 AI 聊天等可选实现。首次使用相应功能时加载；总安装资源不会因此按相同比例减少。`pnpm test:startup` 会重新构建依赖图（不写入 dist）、检查可选实现未进入入口、检查 900,000 字节预算，并验证资源共享与失败重试。脚本也可接收 JSON 报告路径：`node scripts/check-startup-bundle.mjs /tmp/startup-report.json`。

后端启动审阅覆盖 AppState、数据库迁移、锁屏、脱离窗口 AI 会话恢复及 RDP 引擎状态查询；未发现足以在没有 Windows 实测的情况下改动这些边界的证据。本次未修改 Rust 或削弱安全初始化。

## 已执行验证

- 类型检查、生产构建通过。构建仍有 Monaco 等功能分块超过 500 kB 的体积提示；这些是按需分块，不是首屏预算。
- 启动资源加载器的 3 项测试通过：并发共享/缓存成功、异步失败重试、同步异常后重试；生产入口预算检查通过。
- App、编辑器、命令输出、交互输入、Shell 集成和资源加载器合计 150 项回归通过；侧栏状态及实际组件 SSR 回归通过。
- 内置浏览器访问 `tests/startup/`，运行真实 LazyTerminalView 与终端注册表，使用模拟 IPC，不连接远端、不运行本地 Shell。打开终端前引擎资源计数为 0；打开后实例建立、加载前保存的快照恢复，输入 `hello` 被接收。
- 同一终端保持挂载期间注入功能加载失败，显示局部重试提示；重试后成功，终端实例、快照和输入保持。深色提示和 Enter 键重试亦通过。资源计数属于开发环境观察，生产依赖边界由构建脚本验证。
- `tests/sidebar/?theme=light&reset` 挂载真实 App，模拟本地服务：首次打开编辑器工作台、新建文本文件、Monaco 接收输入、首次打开设置均正常。补齐字体枚举模拟后，设置就绪且无未模拟 IPC 报告。没有修改用户真实配置或文件。
- 加载/错误状态使用共享 Button、语义文字与间距 token、status/alert；观察了浅色功能页面和深色错误状态。此次没有改变页面主体布局。

SSR 回归使用独立配置关闭无需的客户端依赖扫描，避免关闭临时 Vite 服务后后台优化继续写入已清理缓存。运行环境的 pnpm 自动依赖检查会尝试联网重装；离线验证以 `pnpm --config.verify-deps-before-run=false ...` 使用现有依赖，未更新依赖或锁文件。

## 验证边界

以上证明首屏代码减少以及模拟服务下功能可用，不能换算为启动快了 63.3%，也不能代替 Windows 原生安装包的冷/热启动计时。WebView2 初始化、杀毒扫描、机械硬盘、真实连接量/历史数据、原生字体枚举和首次终端耗时仍需 Windows 实机观察。加载占位在首次打开功能时短暂显示；没有预加载所有重模块。

本次未完成原生独立窗口、窄窗口、自定义配色和系统减少透明度下的视觉复验；共享组件/语义 token 的复用不等同于这些环境的实机验收。未验证 SSH 实际网络、真实 SFTP 及持续输出压力；输出消费确认与会话归属代码保持原实现。
