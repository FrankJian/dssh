# 文本编辑器

本地与 SSH/SFTP 编辑工作台正在按 [OpenSpec 变更](../../openspec/changes/add-editor-workspace/proposal.md)实施。以下说明当前已接入的操作；任务完成状态只维护于该变更，尚不代表两平台正式发布验收通过。

## 打开与编辑

侧边栏文本编辑器按钮优先返回当前窗口最近使用且仍打开的编辑工作台；没有时才新建，重复点击不会追加标签。顶部窗口/文本图标用于明确新建文本编辑器，与侧边栏编辑器入口使用同一图标。命令面板提供“新建文本编辑器”“打开本地文件”“打开本地文件夹”，无需 SSH。每项 SSH/SFTP 配置也有“打开远程编辑器”命令；SFTP 双栏工具条的“在文本编辑器中打开”可打开单个选择项或当前目录，使用所在栏的实际文件来源。

会话的“文件列表”、命令面板的“打开当前文件列表”及 SFTP 中的“在文件列表中打开”会直接进入新编辑工作台。会话入口默认浏览该来源主目录；SFTP 目录动作打开所选目录。已有相同来源和根目录的工作台会被复用。

左侧导航的“打开文本编辑器”可直接进入本地工作台，再用“打开文件”或“打开文件夹”选择本机路径。设置 → 外观 → 左侧导航栏 → 文本编辑器控制该入口；新用户默认显示，已有导航选择保持原样，可在此开启。显隐会同步到其他已打开窗口，隐藏入口不会关闭文档。主窗口和独立工作台均可使用；顶部任务栏的窗口分离图标（悬浮显示“在独立窗口打开编辑器”）或工作区标签菜单的“拆分为独立窗口”可将整个当前编辑工作台分离使用，保留原有未保存确认。

从会话文件树或 SFTP 文件列表打开文本时，编辑器会沿用该文件树的当前根目录，自动展开并定位所选文件（包括隐藏文件），继续浏览同目录内容。已有文件夹布局恢复时，本次明确点击的文件优先成为活动文件。此前打开的单文件标签可以保留；重新从会话树打开会创建或复用带正确目录的工作区，不复用没有目录的旧标签。系统单文件选择入口仍保留单文件语义。

外层编辑工作台标签与 SSH 等工作区统一样式，内部文件标签仍独立呈现；空工作台有显示编号，同名目录补充父目录或编号，本地/SSH 来源和完整路径通过悬浮提示查看；显示编号不会覆盖已保存的自定义名称。一个外层工作台标签只属于一个本地或远程来源；不同目录可分别打开。内部文件树按需展开、目录优先自然排序，长目录只渲染可见行；单目录超过 10,000 项会提示截断，可改为打开较小目录或使用目录搜索，支持隐藏文件、刷新、活动文件定位、方向键、主修饰键及 Shift 多选。单击文件使用预览标签，双击或开始编辑后固定。文件标签栏“更多操作”包含关闭当前/其他/组内全部、关闭分组和最近关闭重开。侧栏直接显示文件树；已打开文件通过各编辑分组的文件标签切换和关闭，不再重复显示“打开的编辑器”列表。侧栏与正文间的分隔线可拖动调宽，也可聚焦后使用方向键调整、Home 折叠、End 调到最大、双击恢复默认；宽度保存在本机并同步已打开窗口。展开最窄为 120px；向左拖至 80px 以下会显示吸附预览，释放后折叠，拖回或按 Escape 可取消；再次通过文件树开关或视图菜单展开时恢复上次展开宽度。

每个工作台最多同时打开 8 个编辑分组，到达上限后分屏入口不可用；关闭一个分组后可继续拆分。此边界与布局恢复及移窗引用一致。

多组布局时，每组标签栏右侧都有“关闭编辑分组”按钮；关闭某组最后一个文件也会自动收起该组，工作台始终保留一个编辑组。共享文档仍在其他组打开时只关闭当前视图；独有未保存文档会提示保存、放弃或取消，保存失败或取消不会关闭分组。

左右/上下拆分独立于终端分屏；同一文档正文共享，光标与滚动独立。分隔条可拖动、方向键调整或双击等分；文件标签可拖动排序、跨组移动，按 Alt 拖动复制视图。切换到其他工作台不会销毁编辑内容。

“编辑”“选择”“转到”“语言”菜单调用 Monaco 实际动作，缺少提供者的动作不可用；Monaco 正文上下文菜单及原生查找替换继续可用。“问题”只显示本工作台已加载文档的诊断，可点击定位。没有远端 LSP、Git、调试器或扩展市场。

## 保存、编码和比较

保存快捷键为 Ctrl/Command+S。原生窗口在文本编辑工作台激活时显示系统“文件 / 编辑 / 选择 / 视图 / 转到 / 工具”菜单，切换到其他工作区后恢复基础菜单。文件菜单提供新建/打开、保存/全部保存/另存为、重载和项目文件子菜单；编辑/选择调用正文动作，转到提供历史、快捷打开及符号导航，视图提供面板、分屏及预览，工具提供命令面板、语言和比较子菜单。普通输入框保留系统复制粘贴与撤销，模态窗口打开时禁用工作台动作，退出仍检查未保存文件。浏览器预览使用网页菜单降级。

原生搜索、历史导航和窗口分离入口位于顶部任务栏，仅活动编辑器显示；正文只保留文件标签和 24px 面包屑。文件标签栏保留保存、预览和分屏快捷图标。状态栏可选择语言、编码及 LF/CRLF；编码/行尾转换产生未保存状态，语言和显示设置保留撤销历史。文件标签菜单可“以其他编码重新打开”，dirty 文档先处理保存/放弃/取消。

UTF-8（可带 BOM）、UTF-16 LE/BE 和 GB18030 严格解码，不能无损读取时请求选择编码；不猜测替换字符。混合行尾保存前需确认 LF/CRLF，不自动添加末尾换行。另存为成功才改变文档身份；失败保留原路径和草稿，全部保存会报告未成功的文件。

本地和远程保存都验证实际字节版本。文件被其他客户端修改时，可比较、另存为或确认覆盖新检查到的版本；不会无条件覆盖。SFTP 缺少安全替换能力时默认阻止旧目标替换；本次明确接受非原子覆盖后，断线仍可能损坏原文件。临时文件清理失败会显示其路径供恢复。协议局限见 [实现说明](../architecture/editor-workspace.md)。

普通预算为 20 MiB；更大的文本先请求受限模式或取消，受限模式关闭高成本语言分析、minimap、格式化和自动比较。1 GiB 是拒绝上限，并非流畅编辑或一定可加载的保证。不使用截断正文保存。大文件不自动轮询，保存仍验证版本。

未保存文件在正常关闭时受保护，取消或保存失败会保留文档；不持久化正文草稿，因此崩溃或强制终止仍可能丢失未保存内容。正式安装包、真实 SSH 和 Windows/macOS 完整生命周期的证据见 [验证记录](../verification/editor-workspace.md)。

## 快捷打开与目录搜索替换

“快捷打开”按文件名或相对路径进行模糊匹配，可通过方向键/Enter 打开；“目录内容搜索”支持大小写、全词、JS 正则和按文件分组定位。两处均可配置每行一个包含/排除 glob，隐藏文件单独开启，默认不扫描 `.git`、`node_modules`、`target`、`dist`。一次工作台只运行一个扫描，打开另一查询会取消之前的后台枚举。

搜索先使用已打开文档的内存内容，再扫描目录。结果若因后续编辑过期，定位或应用会请求重新搜索；不会用旧磁盘副本覆盖草稿。界面显示进度、停止、读取/编码/二进制/超限/链接统计和截断原因。目录、字节、匹配和 worker 时间均有预算，详情见实现说明；截断查询不能直接确认跨文件替换。

启用“替换”并重新搜索后，可打开逐文件差异预览。确认文字区分“只修改内存”和“直接落盘”的文件数；取消预览不会写文件。应用后的结果分别显示未保存内存修改、落盘成功、冲突、失败或未处理。停止后续替换不会撤销已经成功落盘的文件；失败项重试需要重新确认，冲突应先重新搜索/预览。

设置 → 快捷键中的“编辑器”分组可修改保存、另存为、关闭文件、快捷打开、搜索、查找替换、分组和命令面板绑定。默认 Ctrl/Command+P 为快捷打开、Ctrl/Command+Shift+P 为编辑器命令、Ctrl/Command+W 仅关闭当前文件视图。既有 Ctrl/Command+K 应用命令面板仍可使用。编辑器绑定不会抢占终端 shell 按键；IME 组字、锁屏和弹窗期间阻断编辑动作。

## 文件管理、导航与预览

资源管理器标题旁可直接新建文件或文件夹。右键目录、文件或树的空白处可打开操作菜单，也可在项目上按 Shift+F10；目录内新建、文件同级新建、空白处在工作区根新建。右键已选项目保留多选，新文件创建后展开定位并打开。菜单与顶部“文件”菜单共用新建文件/目录、重命名、同来源移动/复制、删除和复制绝对/相对路径。已有同名目标不会自动覆盖；根目录、主目录和当前工作区根不可删除或移动。删除预览显示数量与路径，并先处理受影响文档的未保存内容；取消最终确认不会丢弃草稿。多项操作逐项报告结果，停止后保留已完成的更改。

面包屑按“目录 › 文件”显示，当前文件带类型图标和强调，悬浮可查看完整路径；工作区内文件会省略根目录之外的冗余上级。长名称在窄分组中缩略，右侧“文档符号”图标保持可见并显示悬浮名称。点击目录会弹出下级列表，点击文件夹继续浏览、点击文件在当前编辑组打开；可筛选名称、显示隐藏项目、返回上级（Alt+左方向键），Escape 关闭弹层。目录列表支持方向键、Enter 和右方向键进入；已打开根目录内不向上越过工作区根。点击面包屑中的当前文件仍可定位文件树；符号面包屑随光标显示嵌套的类/函数/方法，可选择同级符号跳转；“文档符号”仍提供完整原生列表。自动面包屑对 2 MiB 以内正文读取最多 2,000 个符号；没有提供者时显示不可用。“后退/前进”和状态栏行列按钮用于返回位置和行列跳转。

文件标签栏右侧提供保存当前文件、Markdown 预览、向右分屏及更多操作，悬浮可查看名称；更多操作也可向下分屏。Markdown 文件会直接显示预览图标，开启时保持选中；预览在右侧以独立文件标签打开，重复打开定位已有预览；可打开最多 8 个预览并切换，点击预览标签的关闭按钮或在预览中按关闭文件快捷键手动关闭。源文件打开时预览同步正文，切换或关闭源文件/分组后保留最后内容；重新打开同路径文件后恢复同步。预览不保存文件，源文件的未保存确认仍生效。拖动中间分隔线调整预览宽度，Escape 取消拖动；分隔线支持方向键、Home/End 和双击复位。预览快照仅在当前工作台内存保留。标签较多时横向滚动，右侧快捷按钮固定可见。Markdown 可侧边预览，超过 1 MiB 暂停；原始 HTML 不执行、图片不自动联网。图片以只读预览打开，预算 10 MiB。比较菜单可读取磁盘版本或选择同来源另一文件，也可与已保存基线比较；支持内联/并排与上一个/下一个差异。比较不会修改原文。

字体、字号、minimap、行号等沿用设置 → 编辑器。状态栏可调整缩进、自动换行和空白显示，跨窗口同步外观时保留撤销历史。正常文件编辑增长后也可进入受限模式；正文缩回后需重新打开，才重新启用高成本语言功能。JS/TS、JSON、HTML/CSS 使用内置本地语言服务；其他语言按实际提供者显示语法着色及可用动作，不提供远端项目依赖分析或远端 LSP。

主窗口重启并解锁后，可从保存的干净文件引用恢复分组和位置；文件会重新读取并验证来源；独立窗口重新打开同一文件夹也可恢复该文件夹的干净布局。未保存文本和未命名草稿不持久化。顶部任务栏独立窗口动作或工作台标签“拆分为独立窗口”先处理未保存决定，目标初始化成功并确认交接后才释放源工作区；失败或取消保留源文档。

顶部搜索命令中心显示搜索提示、工作区名称与当前快捷键，点击可快捷打开文件；宽窗口居中，窄窗口收为搜索图标，极窄窗口仍可从系统“转到 → 快捷打开”进入（网页预览在“视图”菜单）。文件树和文件标签采用对应文件类型图标。文件切换与侧栏出现使用轻量过渡，系统启用减少动态效果时关闭非必要动效；切换保留正文与撤销历史。

## Markdown 图表和图片

打开 `.md` 文件后，点击文件标签栏右侧的 Markdown 预览图标，可在旁边查看当前内存正文。普通代码块保持代码显示；使用 `mermaid` 围栏可显示图表，也兼容 `mamerid` 拼写，例如：

````markdown
```mermaid
flowchart LR
  A[开始] --> B[完成]
```
````

每幅图右上角的下载图标为“导出 PNG”，点击后选择本机保存位置，远程 Markdown 也导出到本机。导出不会保存或修改 Markdown 正文；取消不写入文件，失败后可重试。输出按原比例以最多 2 倍尺寸绘制，并限制在 1024×4096 像素以内；超大图会缩小。

图表不接受内嵌配置、URL（包括 URL 标签）或外部图片资源。每图最多 64 KiB UTF-8、1,000 个行/分号/连接分段及 500 条边；每篇最多渲染 32 幅，超出的围栏显示为代码并提示。语法或预算错误只影响该图，修改正文后会重新渲染。Markdown 总预览预算仍为 1 MiB，原始 HTML 不执行，正文内嵌图片目前只显示占位信息。

在本地或 SSH/SFTP 文件树打开 PNG、JPG/JPEG、GIF、WebP、BMP、SVG 文件，可直接只读预览，单文件预算 10 MiB。图片加载或解码失败会显示错误及重试入口；SVG 以图片方式显示，不执行其中脚本。这里的图片预览与 Markdown 内嵌图片是不同入口。

## 空工作台打开文件夹

默认的“文本编辑器 1”尚未打开目录、文件或图片时，打开本地或 SSH/SFTP 文件夹会直接复用该标签，保持标签位置和数量；默认名称随目录更新，自定义名称保留。优先使用发起操作或当前选中的空工作台；相同来源的目录已打开时，直接定位原工作台。

已经有目录、文本文件、未命名文件（即使尚未输入）、图片或在途操作时，会保留原工作台，在其他空工作台或新标签中打开目录。选择取消、打开失败不会替换标签；等待期间新建草稿也会在提交前重新检查并保留。明确新建/复制工作台、启动恢复和窗口交接继续使用各自原有流程。

## 文件类型图标

文件树、文件标签、面包屑和文件列表共用内置 Seti 文件图标。TS/JS、Rust、Git、JSON/YAML、Markdown 等显示对应图形；README、TODO、tsconfig.json、Vite 配置等特殊名称优先识别，未知类型使用通用图标。图标支持深浅外观，离线可用；目录展开和链接标识保留，文件图标不改变正文语言或编辑能力。


Markdown 新打开或恢复时默认使用“源码”（Monaco），文件标签栏右侧依次提供源码与铅笔图标，点击铅笔切换“所见即所得”编辑，悬浮显示名称。已打开的文件在当前编辑组内保留自己的模式，切换标签不互相影响；关闭后重新打开回到源码。支持标题、粗体/斜体/删除线、行内代码、列表/任务、引用、表格和代码；“格式”“表格”菜单位于所属编辑组面包屑右侧、文档符号旁，以细竖线分隔，提供排版、链接地址和表格行列操作，常见 Markdown 输入及格式快捷键也可使用。Mermaid/mamerid 代码块下方安全渲染图表并保留 PNG 导出。两模式共用同一正文、保存与撤销栈，切换不自动保存或改写文件。超过 1 MiB 的文档使用源码编辑。查找、替换和行号跳转在源码模式打开，继续使用 Monaco 的现有功能。

富文本修改只序列化变化的顶层区块；未修改区块保留原始 Markdown 写法。Frontmatter、HTML、引用定义及无法可靠往返的扩展语法显示为原文区块，可切换源码编辑；不会执行 HTML，图片只显示引用占位，不自动联网。粘贴采用纯文本以避免载入剪贴板 HTML 的外部资源。未保存关闭、冲突、锁屏和移窗保护继续生效。

所见即所得长文档在正文区域独立滚动，文件标签和状态栏固定。首次打开或切换进入所见即所得从文档顶部显示；普通聚焦不再跳到文末。

文件树顶部操作按新建和视图分组，隐藏文件开关以眼睛开闭及选中背景区分；靶心按钮用于定位活动文件。文件树和面包屑目录列表的刷新按钮在请求期间旋转并暂时禁用，快速刷新也会保留短暂反馈；系统启用减少动态效果时停止旋转，保留忙碌提示。

侧栏展开/收起统一使用左侧活动栏的独立详情按钮，编辑器工具栏不再重复显示切换图标；“视图”菜单仍可显示/隐藏文件树。通过分隔线折叠后，焦点优先回到独立详情按钮，嵌入场景无该按钮时回到“视图”菜单。

没有打开文件的编辑分组显示欢迎页：上方为低对比 Duo SSH 终端符号，下方按行提供新建文本、打开文件/文件夹、已有目录的快捷打开，以及主窗口可用的命令面板；右侧显示实际配置的快捷键。窄分组收起键帽，短窗口缩小或隐藏水印，优先保留可用操作。

欢迎页“显示所有命令”的键帽使用全局“打开命令面板”绑定；修改、重置或在另一窗口调整快捷键后，键帽与顶部搜索提示即时更新。进入空白编辑器会聚焦首个可用操作，可直接使用显示的新建、快捷打开或命令面板按键；输入框、模态窗口和锁屏不会被抢走焦点。

新建文本首次保存或另存为到当前工作区目录后，文件树会自动刷新并定位新路径，保存后可继续在编辑器输入；已有目录展开状态保留。关闭时保存和全部保存也会同步。侧栏隐藏、处于目录搜索或工作台暂不可用时，恢复文件树后再同步；保存到当前根外不会自动切换目录。


所见即所得模式在代码块外粘贴包含 Markdown 代码围栏的纯文本时，直接生成代码块，Mermaid 的方括号和箭头保持原文。在空段落输入三个反引号后立即出现光标旁语言提示，无需先回车；继续输入 me、ya 等前缀筛选，方向键选择、Enter/Tab 或鼠标确认即可建立对应代码块并进入正文。Escape 或失焦关闭提示并保留输入，行内和代码块内部不触发。右下角紧凑语言选择框可搜索纯文本、bash、mermaid、yaml 等，候选只显示一个语言名称，选择后更新代码语言，代码内容保持不变。代码块内部粘贴按原文插入；粘贴及语言修改支持单步撤销与保存，锁定/只读时不可修改。解析超限或组字冲突会提示改用源码，剪贴板 HTML 不执行。
