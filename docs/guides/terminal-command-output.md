# 复制命令输出

终端右上角的闪电图标是“终端超级键”。鼠标移上去时，复制图标向左滑出；移开整个工具区后向右收起。点击复制图标查看当前终端的最近记录。也可以点击闪电展开，或用 Tab 聚焦闪电，再按左方向键或下方向键进入复制图标。

在「设置 → 终端 → 输入与交互 → 鼠标与复制」中，可通过“显示终端超级键”开关隐藏或恢复入口。默认显示，本机保存并同步各窗口；隐藏仅关闭入口与浮层，存活会话的输出记录继续按原规则保留。

- 记录按时间从新到旧排列；同一命令执行多次分别保留。
- 悬停或键盘聚焦命令行可预览输出；点击命令行打开只读详情，支持滚动和选择文本。
- 行尾复制按钮直接复制该次输出；详情中的“复制输出”复制同一份文本，不包含命令、提示符或截断说明。
- 复制成功后原按钮显示“已复制”，不另弹成功通知；复制失败保留错误反馈，可直接重试。
- 无输出的记录显示“无输出”，复制按钮不可用；过长输出显示“输出已截断”。

只记录已结束的非交互命令。识别需要完整的 shell 命令边界标记。普通 SSH 的列表若显示“尚未启用命令识别”，点击“启用本次会话的命令识别”，在空白命令提示符下选择当前 Bash 或 Zsh 并确认。看到“已启用”后重新执行 `ll` 等命令，先前的执行不会补建记录。应用仅发送当前 shell 的临时 hook，不写入配置文件；重连后需重新确认启用。已有冲突 hook、选错 shell 或发送失败会给出提示，不会自动重试。网关菜单及不支持的 shell 不自动配置。运行中的命令、交互程序、认证输入及边界不确定的内容不收录。

每个终端独立在内存中保留最近 20 次记录，单次最多保留开头 1 MiB 纯文本。切换标签不清除记录；关闭终端、重连至新 shell 或重启应用会清除。记录不是完整日志，不会因增大滚动历史而恢复已淘汰内容。
