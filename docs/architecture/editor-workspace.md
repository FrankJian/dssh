# 文本编辑器工作区实现

本次行为与实施任务由 [add-editor-workspace](../../openspec/changes/add-editor-workspace/proposal.md) 管理。当前已接入独立工作台、文档内核、React Monaco 视图和本地/远程版本化文件 provider。文件管理、引用布局恢复与确认移窗已接入；完整原生流程和两平台发布验收尚未完成。

## 文档与视图所有权

`src/editor/documentRegistry.ts` 中的 `DocumentRegistry` 属于一个工作区实例，单独拥有文档模型、保存基线、编码/行尾元数据、保存队列和视图状态。文件来源与后端规范绝对路径组成文档身份；前端不会转换路径大小写。本地、不同 SFTP profile、Windows 盘符/UNC 同名路径保持隔离。

每个文档 model 使用带工作区命名空间和文档 ID 的 `dssh-editor` URI，路径片段经过编码。注册表通过可注入的 model factory 创建缓冲；生产视图使用实际 Monaco model，状态机测试使用受控缓冲以精确安排异步保存结果。

同工作区同文档的多个视图共享 model，光标/滚动按 view ID 保存。挂载时 retain，卸载时 release；卸载不会销毁文档或删除已保存的视图位置。关闭文档必须没有活动视图、没有正在执行的保存，且 dirty 已获放弃授权或已保存；最终由注册表释放内容监听器和 model。销毁整个工作区前必须由宿主完成未保存保护，不能用 dispose 绕过确认。

`MonacoDocumentView` 使用 React wrapper 的 `keepCurrentModel`，并禁用 wrapper 自带按 model URI 共享的 viewState 存储，改用注册表独立视图状态。初始化使用已存在 model，不把 React value 每次回写给 Monaco，因此保留撤销历史。`MonacoComparisonView` 创建独立只读差异 model，关闭时先从 DiffEditor detach，再由比较组件回收临时 model；wrapper 仅销毁视图。

## 保存状态机

dirty 由实际正文、目标编码与行尾相对保存基线计算；未命名文档需要首次保存。基线使用 Monaco 规范化后的有效正文，混合行尾仍保留 `mixed` 元数据，避免首次打开即误报修改；保存读取正文时保留 model 内部 BOM，以免吞掉文件正文中的额外 U+FEFF。重复状态渲染按 model 内容版本缓存 dirty 结果，避免每个标签/状态栏都重建大字符串。注册表不执行文件 I/O，而是把保存快照交给宿主提供的 writer。保存快照含正文、编码/行尾、文件身份与预期版本 token。

同一文档保存串行：队列执行时取最新正文和最近成功的 token。保存期间继续输入不会被旧回执标为干净；失败保留正文、保存基线和原身份。另存为成功才提交新身份，工作区内不能覆盖另一个已打开文档或同时争抢同一另存为目标。

`EditorActions` 统一处理保存、全部保存、另存为、编码重开、重新加载与关闭决定。确认绑定文档 revision；确认期间的新输入会使放弃决定失效。保存冲突可比较、另存为或确认覆盖刚检查到的版本；再次变化仍会重新拒绝。非原子覆盖的授权仅对本次保存有效。

## 文件 provider 与安全替换

`EditorFileProvider` 绑定 Rust 返回的 opaque workspace ID，响应必须属于该文件来源；关闭后的晚到结果不能恢复已释放文档。Rust `EditorManager` 绑定实际调用窗口与来源配置版本，窗口销毁撤销 lease；来源过期、非所属窗口和锁定时拒绝操作。SFTP 复用既有 `require_profile`、TOFU、共享 SSH pool 与短期 SFTP channel，不经 shell，也不新增隐式授权。

读回的 token 绑定来源、规范路径、文件身份/元数据和真实字节 SHA-256。应用内同来源目标保存串行，本地硬链接别名使用文件身份锁。读取验证前后身份，保存先检查旧 token，再写唯一同目录临时文件、完成写入和校验、恢复必要权限，最后再次检查旧目标才替换。新文件要求目标不存在，不静默覆盖。失败保留内存草稿；清理失败携带可恢复的临时路径，不携带正文。

本地拒绝链接及非普通文件；macOS 使用 `fcopyfile` 保留 ACL/stat/xattr 并更新修改时间，Unix 使用安全替换及权限保持，Windows 既有目标使用 `ReplaceFileW`。Windows 实机行为尚未验收，不能由 macOS 测试推断。临时写入、磁盘满、替换拒绝、目标变化、授权撤销和清理失败均有故障注入测试。

远端直接使用 SFTP 协议，探测 `posix-rename@openssh.com` 扩展。保持 POSIX mode，并在必要时保持 uid/gid；能力不足或无法保持元数据时默认拒绝原路径覆盖。仅用户本次明确接受风险后才允许直接写旧文件，断网可能留下部分内容。新文件采用排他临时创建和不覆盖 rename。实际服务器可能不支持 ACL/xattr 等扩展，本实现不承诺保留这些元数据，也不承诺服务器磁盘掉电后的持久性。

SFTP v3 没有通用 compare-and-swap 或 inode 身份，检查与提交之间仍有其他客户端写入竞态；该协议不是跨客户端事务。失败后的再次保存会重新检查版本，不自动重放可能已提交的写入。

## 资源加载与兼容路径

`src/editor/monacoReact.ts` 先等待既有 `src/sftp/monacoLoader.ts` 的本地 ESM Monaco，再向 wrapper 注入相同 Monaco 实例。Editor/DiffEditor 按需导入，不使用默认 CDN。加载失败允许重试，视图卸载后的晚到结果不会新建视图。

当前依赖为 `@monaco-editor/react 4.7.0`、`monaco-editor 0.56.0`、React/React DOM `19.2.7`、Vite `8.1.3`。wrapper 的 peer 范围包含这些版本，安装锁定已验证。共享 loader 继续保留 `loadMonaco` 和主题刷新 API，代码图片工具的 tokenizer 调用方式不变。

左侧导航 editor 为直接打开本地空工作台的动作，不作为连接侧栏分类。`NavigationIconSettings` 与 `useNavigationIcons` 共用既有 `dssh.navigation.icons.v3` 显隐偏好，保留旧值并通过 storage 事件同步窗口；新用户默认显示。隐藏动作只改变入口，不关闭工作台。主/独立窗口同用 `MainApp.openTextEditor`，本地文件/目录选择通过 `chooseLocalEditorPath`，仅选中具体路径后创建工作区，取消不派发文件打开。

从 `LocalFileTree` / `RemoteFileTree` 或 SFTP 列表打开文件时，通过独立的 `rootPath` 字段传递浏览目录，`path` 仍指向所选文件。Rust `open_context` 在规范化路径后分别生成 `rootPath` 与 `initialFile`，检查目录类型和组件边界；独立单文件请求继续允许无根目录。工作区复用会检查传入的目录上下文，防止错误复用旧的无根单文件标签。文件夹缓存恢复后再激活本次明确选择的文件，首次打开时展开并定位其父目录，隐藏文件也可见。

会话、命令面板、AI 文件浏览动作及 SFTP 的文件列表入口直接打开新工作台；无显式路径的目录请求解析本地或远程主目录。无路径的远程单文件请求则创建空工作区，校验来源和锁屏后不建立 SFTP 通道，避免把主目录当作文件检查。单文件引用从干净布局提取初始文件；恢复旧的 `initialFile = null` 引用时同样从布局找回文件路径，真正空的布局继续保持空工作区。

既有 SFTP 双栏和终端 Explorer 的文本打开动作已路由到统一工作台，按实际 local/remote 来源打开；同来源已有工作区中的同一文件可复用。图片继续保留原预览入口，统一工作台也支持受限图片预览与 Markdown。旧服务签名及代码图片 tokenizer API 保持兼容；`RemoteFileEditor` 仍保留图片和无统一宿主回调时的兼容分支。

## 后端编码模块

`src-tauri/src/editor/text.rs` 已提供独立的严格字节编解码与大小预算检查，使用仓库既有锁定的 `encoding_rs 0.8.35`。支持 UTF-8/BOM、UTF-16 LE/BE（保留是否带 BOM）和 GB18030；无 BOM 默认只尝试严格 UTF-8，失败返回可选择编码的错误，不猜测后替换。UTF-16 编码直接输出端序字节，避免 Web 编码库将 UTF-16 输出映射为 UTF-8。

混合行尾和单独 CR 返回 `mixed`，保存前必须显式选择 LF/CRLF；不会偷偷添加末尾换行。扩展名/文件签名安全校验复用 SFTP 规则，解码后的 NUL 仍拒绝，但合法 UTF-16 的原始零字节可以通过。GB18030 保存检查编码错误并往返核对，拒绝有损字符转换。该模块已接入版本化文件 provider，不改变旧 SFTP UTF-8 接口。

## 外部变化与工作台

本地通过 `notify 8.2.0` 非递归监视已打开文件的父目录，避免原子替换使监听失效。每个工作区最多 128 个普通预算内文件；通知合并为 250 ms 的失效提示，仅发送到所属窗口，不发送正文。监听访问事件不会触发循环读；替换监听、关闭和窗口销毁均回收资源。通知不可用时仍保留聚焦、定时和保存时的版本保护。

`ExternalFiles` 串行检查失效提示。当前可见分组最多 8 个普通文件在聚焦及定时检查：本地 15 秒、远程 30 秒；隐藏/锁定时停止新检查并隔离晚到结果。大文件不参与自动轮询，保存仍强制验证实际版本。干净且 revision/token 未改变的文档可自动重载；dirty、删除或连接失败时显示状态并保留正文。重新连接后下次检查可以恢复，旧事件不能授权覆盖。

编辑组关闭与文件标签关闭共用串行决策：按最新布局找出只有目标组持有的文档，收集未保存决定后复核 revision、共享引用及分组成员；期间新增文档或唯一持有关系变化会取消本轮移除。同步布局引用避免同一事件中的布局更新丢失。空组在关闭最后文件后自动折叠，最后一个编辑组保留；关闭活动组后聚焦相邻组，其他组持有的共享 model 不释放。

`groupLayout` 的编辑分组树与终端 pane 无关。同文档跨组共享 model；文件预览编辑后固定、独立 viewState、组间移动/复制、组关闭和最近关闭路径分别管理。工作台被隐藏时保持挂载；锁定使所有视图只读并阻断动作。主窗口关闭先收集文档与终端确认，再冻结并释放资源，原生完整流程仍需安装包验收。

## 目录搜索、快捷打开和替换计划

`editor/search.rs` 的 `ScanManager` 在 Rust 后台执行单根目录扫描，每个工作区最多一个活动扫描；操作 ID 同时绑定工作区和实际窗口。新扫描、取消、关闭工作区和窗口销毁会撤销旧操作。使用点对点 `editor_next_scan` 拉取，有背压：文本通道只保留一份完整文件，文件名通道最多 128 项；不广播正文。目录列举也在到达项预算时停止积累，远端专用原始 SFTP 列举在成功/错误时关闭目录 handle。

上限为 2,000 目录、100,000 项、单文件 20 MiB 和 256 MiB 扫描预算；正则匹配和替换结果最多 2,000 项。为覆盖读取期间增长及失败解码，开始每个文件读取前保留完整 20 MiB+1 的额度，成功后归还未用额度；失败保守消耗保留额度。因此部分损坏文件可能在实际字节数少于 256 MiB 时提前耗尽预算，界面明确显示截断原因。边界不会被二进制或编码失败绕过。

搜索只在规范根目录内部，不递归链接，不读取默认排除目录 `.git`、`node_modules`、`target`、`dist`；隐藏/include/exclude 规则显式传入，glob 每行一项，`**` 可跨目录。打开文件的候选路径也使用相同 Rust 规则过滤，再优先匹配内存正文；磁盘扫描跳过这些路径，避免重复旧副本。无 BOM 的非 UTF-8 文件不猜测编码，计入编码跳过；已按其他编码打开的文档仍可使用内存搜索。

JavaScript 正则在独立可终止 worker 中运行，每文件 1 秒预算，保留 JS 捕获组/命名组/替换 token 语义，匹配位置使用 UTF-16 行列。零长度匹配按 Unicode 码点推进；无效表达式不产生替换。快捷打开也在 worker 模糊匹配路径，只显示前 100 项。查询 generation 和 AbortSignal 隔离晚到结果，取消会停止后续派发并释放 worker；已经开始的有界本地阻塞 I/O 会自然结束。

`searchRunner` 产生绑定原文、文档 revision 或文件 token 的替换计划；预览前零修改。确认显示内存文档数与直接落盘文件数，逐文件 Diff 可查看。`replacePlan` 应用前重验版本、只读、是否在预览后新打开；打开文档使用 Monaco 可撤销编辑并保持 dirty，未打开文件使用版本化安全保存。能力不足不会在批量替换中自动接受非原子覆盖，单项失败会报告，取消保留已落盘成功结果。重试需重新确认失败项原计划，不扩大版本或隐式重试冲突。

## 文件管理与导航

文件树操作使用窗口/来源绑定的文件操作 ID。创建使用排他创建，重命名/移动不覆盖同名目标；本地复制先写临时目录后排他提交，不递归符号链接。删除先列出计数和有界路径预览，保留根目录、主目录与工作区根保护；取消只停止后续操作，已完成结果不会虚报回滚。重命名、移动和删除路径涉及已打开文档时，先收集保存/放弃决定，最终确认后等待所有视图卸载和 model 关闭，再修改文件系统。最终确认取消仍保留原草稿。复制使用磁盘中已保存内容，保留源文档及其草稿；选中的父路径覆盖子路径，不重复操作。操作 ID 初始化后若受影响文件又被打开，执行会被拒绝并请求重新确认。

文件树每个目录最多列举 10,000 项，并显式显示截断；缓存最多 50,000 项及 8×1024² 个路径/名称字符，展开最多 64 层。界面只挂载视口及少量预取行，键盘定位先滚动再聚焦。折叠/刷新释放不需要的缓存；刷新串行读取，过期请求使用单调递增序号隔离。路径面包屑在当前工作区根内定位文件树；符号面包屑显示光标所在的类/函数/方法等嵌套作用域，可从兄弟符号菜单定位。自动符号读取复用 Monaco 的真实 DocumentSymbolProvider，限制在 2 MiB 内正文、2,000 个符号、24 层与每次 1 秒，并按 model 版本去重、去抖和隔离晚到结果。Monaco 0.56 的符号注册表通过单独的版本适配边界读取；不可用、无提供者或超预算时保留原生文档符号菜单，不猜测代码结构。导航历史只在内存保存最近 100 个位置。侧栏仅保留文件树/搜索，已打开文档通过文件标签管理，不再渲染重复的打开文档列表。

## 预览与偏好

`useMarkdownPreviews` 独立管理最多 8 个预览标签与每个不超过 1 MiB 的内存正文快照；按文件身份复用，订阅 registry 同步仍打开的源文件，源模型释放后保留最后快照，同路径重新打开后恢复同步。预览不持有隐藏 model，不进入持久化文件引用，只有预览时也不能认领为空工作台。`EditorMarkdownPane` 持有可取消的比例调宽与预览标签键盘焦点，预览关闭不调用文件保存/关闭；工作台按预览焦点分派关闭快捷键，避免关闭来源文件。锁屏和交接阻断预览操作及渲染/导出。

Markdown 使用 ReactMarkdown/GFM，忽略原始 HTML，不自动请求文档图片；只允许用户点击后经系统打开 HTTP(S) 链接。正文超过 1 MiB 暂停 Markdown 预览。图片走绑定工作区的 `editor_read_image`，复用 10 MiB 预算，只以 data image URL 放入 img，不作为网页执行。Diff 可比较保存基线、重新读取的磁盘正文和同来源另一文件，支持并排/内联与差异跳转；临时 model 与正文 model 分离。

共享注册表 model 初始为 plaintext。React wrapper 复用已有 model 时不应用初始 language prop，因此视图挂载显式设置实际语言；后续语言变更由 wrapper 更新，保留撤销历史。字体、字号、minimap、行号、缩进、自动换行和空白显示沿用原编辑偏好键，通过 storage 事件同步窗口。

## 引用恢复与窗口交接

`layoutReferences` 按白名单导出干净文件的路径、编辑分组比例、活动文件及光标/滚动位置；dirty/未命名文档、正文和凭据不进入引用。布局解析限制节点、文件数、路径长度并丢弃未知字段。工作台创建分组与引用契约统一限制为 8 组；命令执行前同步检查最新布局，防止同一事件连续拆分绕过 React 渲染后的禁用状态。主窗口使用独立键 `dssh.editor.workspaces.v1` 保存最多 16 个工作区引用；所有窗口另有按来源与规范根路径区分的文件夹布局缓存，重新打开该文件夹时恢复干净文件；正常关闭工作台会移除其引用。启动解锁后重新调用 workspace/provider 检查路径和来源，读取实际正文。无法读取的来源会保留失败提示；这不是崩溃草稿恢复，不改变连接配置或备份导入导出语义。

移窗先处理所有未保存决定，再冻结源编辑器。只向目标窗口交接有类型的文件引用和布局，不广播正文。目标重新打开自己的 opaque 工作区，所有活动 Monaco 视图初始化后才报告 ready；目标在提交前只读。source/target 的实际窗口标签和随机 handoff ID 共同约束确认。源收到 ready 后再检查 revision、锁屏和关闭状态，后台提交才撤销源 lease；目标收到 release 后可编辑。超时、失败、取消、目标销毁或提交拒绝都保留源文档并解冻。正式安装包中的完整多窗口行为仍待原生实机验收。窗口关闭由 `coordinateEditorWindowClose` 先收集全部编辑决定、再确认运行终端，最后重新验证 revision 并冻结/释放；任一取消或保存失败不进入资源释放阶段。锁屏时已提交保存可以完成，排队但尚未派发的保存会被阻断；解锁不自动重放。

## 编辑器界面分区

`EditorWorkbench` 原生正文保留文件标签与紧凑面包屑，搜索和导航在宿主标题栏，分类菜单在系统菜单栏；网页环境保留单行工具栏降级。菜单与可见按钮复用现有命令/保护。`EditorSidebar` 单独管理 Explorer/搜索的鼠标捕获、键盘调宽、取消/卸载清理及有限宽度，不重建文档。宽度使用独立本机键 `dssh.editor.sidebarWidth`，通过 storage 同步窗口，不写正文或连接配置。

`workspaceLabels` 只计算外层工作台的显示编号、重名路径上下文及来源，原始名称仍用于重命名和持久化。外层统一编辑器图标，内部为文件图标；工具栏的独立窗口入口调用 App 既有 `handleDetachTab` 与交接协调，不增加第二套窗口/dirty 处理。

### 退出期间的窗口集合

`ApplicationExit` 与 `DetachedWorkspaceManager` 共用窗口创建门闩：构建独立窗口时持有门闩，退出先设置 busy，再在全程 90 秒预算内等待既有构建结束并拍摄参与者快照。后续构建在创建原生窗口前被拒绝，移窗失败沿用既有回收流程，取消退出后可重试；已批准退出时仍拒绝创建。准备与复核要求归属集合完全一致；提交允许既有窗口正常清理归属记录，但不允许出现未确认参与者，且各原生参与窗口仍须存活。每次请求前、等待回执的心跳及最终退出前均复核；创建被拒绝时回收尚未交接的终端输出缓存。此机制不把默认 Command+Q 通过结果等同于 Dock 或系统注销的实机证明。

### 侧边栏编辑器定位

`useWorkspace` 在每个窗口内维护仍打开编辑器的最近使用顺序，打开、恢复、切换工作台均更新该顺序，关闭时移除对应项。侧边栏通过 `openEditorEntry` 定位最近项，没有时调用既有创建入口，并合并该入口的在途创建请求；不同窗口不共享该顺序或正文。App 保留锁屏、退出协调与交接阻断，并在定位后退出其他活动页/会话树展示。标题栏与命令面板的“新建文本编辑器”继续直接创建，不经过侧边栏复用逻辑。

## Markdown 图表与栅格导出

`EditorMarkdownPreview` 使用 remark 插件识别 `mermaid`/`mamerid` 围栏，共用 `sftp/MermaidDiagram`；插件只改预览 AST，不改 Monaco 正文。每文档最多 32 幅图，之后提示并回退普通代码。共享组件通过本地懒加载 Mermaid，以串行队列隔离全局初始化配置，每项让出事件循环并检查存活状态；队列不保留最后一幅 SVG。临时离屏宿主在成功、失败后均删除。

渲染遵循 Mermaid 的 [strict 安全配置](https://mermaid.js.org/config/schema-docs/config-properties-securitylevel.html)，关闭 HTML labels 和错误插入，限制文本、边数，并额外拒绝内嵌配置、协议/URL、图片及 CSS 外链。SVG 仅作为图片 URL 显示，不注入 HTML 或绑定图表回调。图片文件也使用图片上下文，失败显示可重试反馈；Markdown 正文内嵌图片仍不加载。

`mermaidImage` 将 SVG 转为本地 Blob 图片，在画布填充应用背景后按比例绘制并调用已有 `canvasPng`；根 SVG 尺寸样式被显式尺寸替换，输出遵守已有图片保存服务的 1024×4096 像素边界，临时 Blob URL 总在结束时释放。每图 UTF-8 64 KiB、1,000 个行/分号/连接分段、500 条边为输入预算，不承诺复杂布局的硬执行时限。导出复用 `saveToolImage`/`save_tool_png`，未新增 Rust 命令或远端写入能力。

导出捕获当前正文、主题及操作代次；文档变化、锁屏、窗口交接或卸载后，尚未交给原生保存服务的旧结果被丢弃，解锁后也不重放。原生对话框已启动的操作继续遵循既有保存服务生命周期，不能承诺撤回已开始的系统保存。取消/失败不修改正文和 dirty 基线。

## 顶部分类菜单

原生菜单提供文件、编辑、选择、视图、转到和工具，网页降级在工具栏提供文件、编辑、视图和工具四个文本菜单；文件标签栏保留所属组的保存、预览和分屏。菜单中的保存使用当前活动文档，标签栏按钮使用所属文档，同一动作只调用一次既有服务。窄窗口保留原生系统菜单或网页降级菜单的可达性。

`EditorFileManagement` 公开既有菜单项并可隐藏自身触发按钮；文件菜单将这些项合入“项目文件”分组，仍由原组件持有选择快照、确认、取消、停止、反馈和后台动作。菜单项公开时同步 enabled/busy 状态，执行仍检查现有授权，不增加第二套文件操作路径。网页菜单沿用共享 `EditorActionMenu` 的键盘、焦点及窗口边界约束，原生菜单使用同一能力与动作模型。

## 侧栏吸附折叠

`EditorSidebar` 将已保存的展开宽度与本次拖动预览分开：展开最小 120px，拖动小于 80px 时将预览宽度吸附为零并让内容 inert/隐藏，保留捕获指针的分隔线；释放才通知宿主隐藏侧栏。向右拖回恢复预览，Escape、pointercancel、lostpointercapture、失焦、禁用或父区域尺寸变化取消拖动，不写入临时宽度。只有正常完成的展开调宽才更新既有宽度偏好，因此折叠后重新挂载侧栏仍恢复上次展开宽度。

Home 或最小宽度处继续向左可键盘折叠，宿主将焦点返回文件树开关；End 到最大宽度、双击恢复默认。锁屏、交接、非活动和文件操作期间分隔线禁用。正文/model 不随侧栏重建。顶部任务栏的独立窗口动作使用共享 undock 图标，保留原动作、可访问名称及交接保护。

## 空工作台复用目录

`App.openTextEditor` 仍先经后台创建和验证目录工作区，再优先定位同来源、同规范目录的已有项。普通目录打开调用 `reuseEmptyEditorWorkspace`，优先尝试发起/活动标签，其次尝试本窗口其他空项。`EditorWorkbench.claimEmpty` 同步检查来源元数据、注册表（含空白未命名）、图片引用、恢复/异步操作和锁屏/冻结/文件操作/交接状态；成功后立即阻断旧空工作台操作。读取与界面发起的异步命令有在途计数，图片状态同时更新同步引用，防止渲染尚未提交时错误判断为空。

`useWorkspace` 维护同步标签快照，新增/关闭/重命名/替换都更新同一来源；`replaceEditorTab` 校验预期后台工作区身份，避免同一事件中的并发打开或关闭操作使用旧列表。替换保留外层标签 ID、顺序和历史，后台工作区 ID 则使用新目录的 ID，两者不再承诺后缀相同；文件、关闭、移窗继续从标签对象读取当前 workspace。替换失败解除空项冻结，成功清理旧持久化引用并释放旧后台工作区，旧快照回调按后台 ID 拒绝。Workbench 以后台 ID 为 key 重新建立目录来源和恢复布局，不带入旧空状态。尚未交给标签的后台工作区在打开异常时清理。

恢复或明确新建不参与复用；正在分离窗口的标签排除。此机制不迁移已有正文或草稿，也不改变既有存储键、连接授权或文件保存服务。

## 路径与符号导航排版

每组面包屑使用语义路径列表、统一方向分隔符、共享文件类型图标及当前页标记；仅对该工作区内文件过滤根目录外祖先，完整路径通过条目和导航的 title 保留，目录枚举预算及定位服务不变。路径名在有限宽度中缩略，当前文件优先保留空间；右侧符号链可独立滚动，文档符号入口固定并使用共享图标按钮。

符号链为空或禁用时同步隐藏，嵌套符号之间使用相同分隔语言。导航仍调用现有树定位与 Monaco 提供者，键盘和菜单焦点沿用共享控件；路径与文档符号入口在非活动、锁屏、冻结或交接时禁用。改动不重新创建 model 或变更文件内容。

## Seti 文件类型图标

共享 `FileEntryIcon` 的文件图形改为内置 Seti 字体；目录与链接覆盖继续使用共享 Icon。`fileIconTheme` 从固定 JSON 建立 Map，优先精确名称、最长复合扩展名，再使用独立的语言扩展名后备；后备映射补足 VS Code 语言扩展通常提供的关联，不加载扩展代码或改动 Monaco 语言设置。大小写归一化只用于图标识别，不影响文件身份或路径。

字体和主题映射固定在 `src/assets/seti/`，来源版本及摘要见该目录 README；MIT 许可说明位于 `public/licenses/seti.txt`，随 Vite 输出进入应用包。未新增 npm 依赖。文件字形通过 aria-hidden 装饰元素的 CSS 伪元素显示，不将私用区字符加入文件名 textContent；颜色使用对应深浅主题变量，未定义颜色的图标回退现有代码图标 token。字体由本地资源 URL 加载，无每行观察器或外部字体请求。


## Markdown 所见即所得

`MarkdownModeSwitch` 在所属文件标签栏右侧复用共享分段控件的图标/单选语义，采用平面选中态与名称提示；Workbench 以组/文档组合身份在内存保留当前模式，新打开或恢复统一为源码；旧 `dssh.editor.markdownMode` 键保留但不再读取或写入，文件/组关闭时清理对应模式。`MarkdownDocumentView` 仅渲染选中模式，正文仍在原 registry 的 Monaco model。`RichMarkdownView` 懒加载 Tiptap/ProseMirror、GFM 任务/表格与 Markdown 适配器，独立 retain/release 文档视图，不创建另一份可保存的富文本文档。富文本差异以最小文本替换进入 Monaco 撤销栈；源码、其他分组、外部重载与撤销更新重新解析富文本，自发更新不重置光标。IME 期间延迟外部同步，过期的富文本事务不覆盖已变化的源码。

`RichMarkdownAdapter` 使用 remark GFM 顶层位置记录原文、空白分隔和语义指纹。原文经 Tiptap 解析/序列化后的 AST 不等价时保留为原文块；富文本更新仅对变化区块序列化，其余字节写法保持。保护 frontmatter、HTML、引用定义和未知扩展；限制 1 MiB / 2,000 顶层区块，超限或失败可使用源码。图片节点以文本占位显示，原始 HTML 只用 DOM 文本显示，粘贴仅读取纯文本，禁止外部拖入 HTML 和默认链接跳转；沿用 Mermaid 安全组件。自定义代码节点视图与扩展内置节点视图合并，保留任务勾选和表格行为。

两种视图通过各自句柄参与初始化 ready、焦点、原生撤销/重做和冻结；锁屏/交接立即阻断输入及晚到事务。富文本 JSON、正文快照不写入偏好或布局引用。依赖选用开源 Tiptap 3.35.0 的 [MarkdownManager](https://tiptap.dev/docs/editor/markdown/api/markdown-manager) 与 [表格组件](https://tiptap.dev/docs/editor/extensions/nodes/table)，未使用云服务或付费功能；转换接口仍需由适配器的往返与原文回归保护。


## 面包屑目录浏览

`EditorBreadcrumbDirectory` 在路径目录按钮打开单目录弹层，调用当前来源的 `EditorFileProvider.list`，复用自然排序/类型图标及共享浮层控件。导航和筛选只在弹层内存维护，不改变工作区根与文件树。打开文件携带触发组 ID，异步读取完成后仍写入该组；若组已消失，清理没有视图、未被其他组引用且无修改的读取模型，不另找其他组打开。

每次目录请求绑定递增 generation；关闭/禁用/卸载或后续请求使旧结果失效。根目录内限制向上导航边界，继承符号链接目录不展开；无目录工作台也能浏览路径祖先，后台仍验证实际窗口、来源和连接版本。单次最多 10,000 项 / 8 MiB 名称与路径，只有当前列表保留；弹层以 32px 行高虚拟化，筛选、隐藏、空状态、错误重试及键盘焦点不要求全量 DOM。浮层关闭于外部点击、失焦/窗口尺寸变化及所属文件切换；Escape 返回触发器，锁屏/交接关闭并隔离结果。

富文本正文通过 `editor-group__content` 的纵向 flex 与 overflow 约束获得有限高度，`editor-rich-scroll` 承担独立滚动并预留滚动条空间。初始化解析后明确选择文档起点并归零滚动，普通句柄聚焦使用 `scrollIntoView: false`；正常用户编辑仍由编辑器滚动到光标，源码查找/跳转路径不变。正文内不再放置胶囊模式条或单独的排版工具行；每组提供面包屑右侧宿主，RichMarkdownView 将既有格式/表格菜单 portal 到本组文档符号旁，用细竖线分隔。宿主按组维护并在模式切换/分组关闭时清理，动作与选区继续绑定原富文本实例。


## 原生菜单与标题栏命令中心

`nativeMenuModel` 从工作台现有动作生成有界菜单树和动作映射，过滤重复剪贴板项并将项目文件、比较等组织为子菜单；`useNativeEditorMenu` 发布当前窗口的可见性、能力和输入上下文。只有活动工作台持有发布令牌，后台工作台和旧实例清理不得覆盖前台菜单。`NativeEditorMenus` 缓存显式基础菜单，按聚焦窗口应用动态菜单；macOS 使用应用菜单，其他原生平台使用窗口菜单，避免反复修改默认 Window 菜单。后台校验叶节点启用及所有者，前端再验证活动、锁屏、模态和当前能力后调用原动作。普通文本输入的撤销/重做与剪贴板由系统预定义项处理，退出继续使用 `ApplicationExit`。

原生宿主给活动编辑器提供标题栏 portal 容器，Workbench 将搜索、历史及分离动作放入其中，不再渲染正文网页菜单行；非原生场景保留原网页菜单。快捷打开仅调整共享 Dialog 和列表呈现，扫描工作器、取消、预算及来源边界保持。

富文本围栏粘贴通过独立 `RichMarkdownAdapter` 解析并清除来源身份键，避免覆盖现有文档的原文映射；代码块内粘贴保持逐字文本。自定义代码 NodeView 使用独立 React 根呈现右下角语言 ComboBox 与安全 Mermaid，语言选择提交节点属性并保留正文。输入筛选与语言提交分离；DOM 事件清理绑定捕获的宿主元素，避免 StrictMode 重挂载留下重复撤销监听。


`fenceLanguageCompletion` 是所见即所得编辑器前置的 ProseMirror 插件；只对可替换为代码块的围栏段落末尾提供临时候选视图，语言目录与右下角选择器共用。候选浮层挂在 body 并随光标、滚动和窗口尺寸定位，不移动正文焦点；确认时使用单个文档事务替换围栏段落并创建 Monaco 撤销边界。Escape/失焦只关闭视图，组字、只读、锁屏及卸载关闭并清理监听和 React 根。完整 fenced 粘贴保持原安全解析，仅单行围栏前缀按文字插入以参与即时提示。

代码块语言控件以局部样式覆盖共享 ComboBox 的 flex 拉伸，使用 128px/24px 并允许窄内容收缩；共享组件的可选 singleLabel 仅影响候选呈现，编辑器显示语言 value（纯文本回退 label），仍以原 value/label 搜索。emptyMessage 为编辑器提供语言提示，其他调用保留原默认呈现与文案。


共享 Monaco 主题桥接将 CSS 语义色通过浏览器 1px sRGB Canvas 转为保留透明度的十六进制，覆盖 rgb 与动态混合色；Monaco 仅按十六进制解析主题，不直接接收 CSS 色函数。查找替换使用完整的浮层、输入、焦点与选项/错误颜色，视觉样式保留 Monaco 原有动态尺寸与窄屏分级，只覆盖常规边界、圆角、按钮和轻阴影；无结果提示使用中性色，非法正则保留输入错误反馈。


`EditorFileTabs` 为文件/预览共用的独立滚动视口，标签不随数量 flex 收缩，最大宽度限制于 240px 和当前视口，极窄时也可完整显露当前项。溢出状态驱动两侧箭头，纵向滚轮仅在能移动时映射横向，原生横向手势保留。打开/切换、当前标签获焦和视口 ResizeObserver 以局部 scrollLeft 显露当前项，不调用全页 scrollIntoView；标签自身宽度观察只更新溢出状态，避免未保存标记出现时重置手动滚动。监听和观察器随组/预览卸载清理，原键盘、关闭与拖动事件保持。


`monacoFindHover` 是独立的 Monaco 0.56 服务适配边界，随共享编辑器懒加载安装一次，使用包规范子路径导入以与主编辑器共用服务单例。仅给 find-widget 目标的即时/延迟原生悬浮补充所属 document.body 容器，保留原定位、内容、快捷键和可访问性；不放开正文 overflow 或改变其他悬浮。对服务方法做运行时兼容检查，以符号标记避免同组即时重入重复包装。显示期间临时跟踪隐藏/移除、滚动、键盘、窗口变化/失焦与模态，隐藏后清理监听和计时器，不留脱离编辑器的旧提示。
