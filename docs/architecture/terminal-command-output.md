# 命令输出记录实现

行为以 [OpenSpec 主规格](../../openspec/specs/terminal-command-output/spec.md) 为准；任务记录保留于[归档变更](../../openspec/changes/archive/2026-11-22-terminal-command-output-copy/tasks.md)。

## 识别与文本

首版要求完整、有序的 OSC 133 A（提示符开始）、B（命令输入开始）、C（执行开始）、D（执行结束）。无标记、自定义不完整集成及网关菜单不生成记录，原有终端运行指示仍按自己的启发式规则工作。历史回放只能恢复尚未提交的提示符/输入状态；命令提交与执行 C/D 边界必须来自 live 流。不会自动执行探针或修改本地/远端 shell 配置。

命令文本只从 B/C 之间的可见回显获得，输入事件只确认提交或排除运行期交互；隐藏输入不作为命令文本来源。认证提示、运行中输入、全屏/复杂控制、常见交互命令及嵌套 shell 被保守排除；标记是 shell 提供的元数据，不是对恶意程序输出的真实性认证。无法自动证明任意程序均为非交互，因此不保证所有普通命令都会收录。

独立增量解析器接受颜色、标题及链接元数据，处理 CR/退格覆盖、行尾清除、tab 和逻辑换行，不受 xterm 显示宽度影响。复杂光标移动、非 ASCII 行上的光标重写或屏幕模式使候选失效；普通 Unicode 文字与换行仍可保留。控制串与命令回显上限均为 4096 字符；解析器不响应设备查询，不向 PTY 写入内容。

## 容量与归属

每终端最多 20 条完成记录、至多一个候选；单次保留最多 1 MiB UTF-8 纯文本前缀。超限冻结正文但继续解析控制与交互标记，记录明确标记截断。正文块定期合并，避免大量短行产生无界对象数；预览只取前 4096 字符中的 8 行，每行最多 240 字符。UTF-8 上限不等于 JS 堆或 RSS 上限。

捕获跟随会话流，不随 TerminalView 挂载和主题变更重建。只消费 live 有序输出，回放仅恢复未提交的提示符/输入状态，不补建记录；缺口/过载/断线取消候选，重连清空旧 shell 世代，关闭或移出原窗口释放记录。独立记录不受 scrollback 淘汰影响，不改变 ACK、显示历史或命令补全的存储行为。

输出只留在内存，不写 localStorage、数据库或日志。移窗请求携带类型化记录，Rust 在创建窗口前按源窗口会话归属、每会话条数与正文字节数校验，并暂存在私有内存映射；仅调用窗口自身可通过专用接口一次性取走，关闭/创建失败会释放待交接内容。输出正文不进入全局工作区描述及广播；详见对应实现与 [验证记录](../verification/terminal-command-output.md)。


## 显式临时 shell 集成

普通 SSH 的无标记会话可在输出列表中显式启用 Bash/Zsh 集成。准备接口只读取当前提示符与输入/输出版本，返回绑定窗口和会话的批准载荷；确认提交校验锁屏、窗口归属、会话类型/状态与版本，再原子入队固定脚本。归属锁保持到入队结束，移动窗口期间不会把旧批准提交到新窗口；取消对话框不发送脚本。

Bash 使用无冲突 DEBUG trap，并在既有 PROMPT_COMMAND 字符串/数组前后插入处理，保留原提示符及退出状态；已有 DEBUG trap、PS0、functrace/extdebug 或只读配置时拒绝覆盖。Zsh 扩展既有 hook 数组并包装提示符，保留已有命名 precmd；在 PROMPT_EOL_MARK 前放置结束标记，避免将 Zsh 补齐行的字符记入输出。重复安装由当前 shell 的私有标记去重，不导出安装状态，也不写任何 shell 配置文件。

状态通过固定 ready/unsupported/conflict 标记确认，5 秒无确认则失败，不把成功入队当作已启用。初始回放只恢复解析上下文，不用旧标记宣称当前 shell 已启用，也不发脚本；可用状态须由当前 live 标记确认。脚本自身是前导空格的内置单行 eval，安全编码后小于常见 PTY 单行容量；不会被记录或写入应用的命令补全历史。脚本内容固定，不包含用户命令、密码或输出；远端 shell 仍遵循其自身历史配置。
