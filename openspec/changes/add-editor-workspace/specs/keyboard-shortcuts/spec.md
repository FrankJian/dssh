# 编辑器快捷键增量规格

## ADDED Requirements

### Requirement: 编辑器命令与快捷键注册

系统 SHALL 在既有命令面板与快捷键设置增加编辑器上下文：新建/打开文件/文件夹、保存/全部保存/另存为、关闭文件、快捷打开、命令搜索、行/符号跳转、文档与目录查找替换、格式化、分组/焦点切换、比较与侧栏切换。默认尽量遵循 VS Code 的平台习惯，macOS 使用 Command、Windows 使用 Ctrl；沿用旧绑定存储和优先级，不占用已有自定义组合，所有入口显示当前绑定。

#### Scenario: 默认快捷打开与自定义冲突
- **WHEN** 用户已有其他命令占用编辑器建议的快捷打开组合
- **THEN** 原绑定保持有效，新增命令可从面板访问并重新绑定，不静默替换已有配置。

#### Scenario: 编辑器内关闭文件
- **WHEN** 用户在编辑器聚焦时执行关闭文件快捷键
- **THEN** 仅关闭当前文件视图并执行未保存保护，不错误关闭整个工作区、终端或原生窗口。

### Requirement: 编辑器焦点与命令路由

系统 SHALL 按锁屏/模态、输入法组字、当前窗口与焦点上下文路由命令；编辑区、文件树、搜索框和普通输入各自保留文本按键，编辑器专属快捷键不得触发后台终端或其他窗口动作。相同操作经菜单、工具栏、命令面板与快捷键执行时共享能力判断、只读状态和确认流程，不产生重复派发。

#### Scenario: 编辑区与终端切换
- **WHEN** 用户先在编辑区执行查找/复制，再聚焦终端按 Ctrl+C
- **THEN** 编辑命令只作用当前编辑文档，终端接收其原有中断输入，不触发后台编辑器命令。

#### Scenario: 输入法组字和弹窗
- **WHEN** 用户在中文输入法组字期间按键或确认框处于打开状态
- **THEN** 不触发保存、分组、关闭等后台动作，按键只进入当前输入/弹窗的合法处理路径。

#### Scenario: macOS 原生菜单与编辑区
- **WHEN** macOS 主窗口或独立窗口的编辑区获得焦点，用户执行撤销、重做或关闭文件
- **THEN** 原生菜单不抢占编辑器快捷键，菜单动作复用当前编辑器命令与未保存保护；普通输入、其他工作台及锁屏不接收后台编辑命令。
