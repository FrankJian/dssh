# Design

## Context

动机见 [proposal.md](proposal.md)。现有工具组件以 portal 菜单展示功能；光标设置已有本机存储与订阅同步模式。终端输入捕获与视图分离。

## Goals / Non-Goals

保持闪电位置和会话身份稳定，只切换入口的挂载，不销毁捕获器或 xterm。不改变远端集成、记录容量、配置导入导出和输出持久化语义。

## Decisions

- 用与闪电连续的左侧工具槽代替文字菜单。短距离横向位移加透明度过渡；收起时禁用点击与 Tab，减少动效时关闭过渡。键盘聚焦闪电展开，方向键进入复制图标，Escape 关闭并恢复焦点。区分鼠标和键盘焦点，避免鼠标点击后永久展开。
- 新增独立布尔偏好，默认 true；同窗口发布订阅，其他窗口通过 storage 事件重新读取。保存成功再发布，失败由设置行反馈。复用共享 SettingsSwitch，不扩展所有 pane 的 props。
- 可见性订阅位于工具组件外层，隐藏时卸载内层入口及 portal 并清理定时器，记录存储与会话流不受影响。仅 CSS 隐藏会遗留浮层与焦点，因此不采用。
- 复制成功复用记录级反馈状态，直接改变对应按钮文案与图标；不另加成功 toast 或提示段落。行尾点击显式聚焦，确保成功反馈可见；失败沿用原有错误反馈并允许再次点击。

## Risks / Trade-offs

- 移动到复制图标时误收起 → 连续命中区域及共享 pointer 事件。
- 多窗口状态滞后 → 按实际存储重读，忽略无关键，支持清除回到默认。
- 隐藏时失去焦点 → 释放浮层，设置窗口继续管理自身焦点。

## Migration Plan

新增本机偏好键，未设置时显示；回退版本忽略新键即可。
