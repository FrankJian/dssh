# Proposal

## Why

当前闪电入口通过浮层文字菜单访问复制功能。用户希望悬停时直接向左滑出复制图标，并可在设置中隐藏右上角超级键，减少终端遮挡。

## What Changes

- 闪电超级键右侧位置固定，悬停时复制图标向左滑出，移开工具区后向右收起。
- 复制图标直接打开最近命令输出列表；保留点击、键盘、焦点恢复与减少动效等效操作。
- 设置 → 终端 → 输入与交互新增“显示终端超级键”开关，默认开启，本机保存并同步所有存活窗口。
- 隐藏时关闭入口与相关浮层，但不清除会话内输出记录或改变捕获/复制资格。
- 复制成功仅在对应按钮显示“已复制”，不再附加成功通知；失败继续反馈并允许重试。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `terminal-command-output`: 超级键的滑出工具交互和可持久化显示偏好。

## Impact

终端输出工具组件、样式及终端设置；复用本机偏好订阅和共享 SettingsSwitch，不修改 Rust、数据库、远端集成或配置导入导出。
