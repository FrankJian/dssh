# 命令输出工具入口

## MODIFIED Requirements

### Requirement: 魔法工具入口与最近记录列表

系统 SHALL 在对应终端 pane 提供带可访问名称的闪电超级键。鼠标进入时“复制命令输出”图标向左滑出，移开工具区后向右收起；支持点击和键盘等效操作，减少动效时立即切换。激活复制图标后展示当前终端记录及执行时间；无记录时呈现空状态。记录行尾 SHALL 提供直接复制输出的独立按钮，不触发详情弹窗或向 PTY 发送输入。

#### Scenario: 分屏与直接复制

- **WHEN** 用户在某分屏的魔法工具中打开列表并点击一条记录的复制按钮
- **THEN** 只复制该分屏终端中该次执行的保留输出，不打开弹窗、不切换目标、不执行命令。

#### Scenario: 键盘访问与空列表

- **WHEN** 用户通过键盘聚焦并打开魔法工具，当前终端没有可用记录
- **THEN** 可访问“复制命令输出”及其空状态，Escape 可关闭浮层并将焦点返回触发控件。

#### Scenario: 悬停滑出与收起

- **WHEN** 鼠标进入超级键并移动到滑出的复制图标，再离开整个工具区域
- **THEN** 闪电位置固定，复制图标先向左展开并可直接打开列表，移开后向右收起；收起图标不能拦截终端输入，界面按键不发送到 PTY。

## ADDED Requirements

### Requirement: 超级键显示偏好

系统 SHALL 在终端设置中提供默认开启的“显示终端超级键”开关，本机持久化并同步主窗口、分屏和独立窗口。隐藏入口时关闭相关浮层，但不清除记录或改变捕获资格；保存失败时保持原状态并显示错误。

#### Scenario: 隐藏与恢复

- **WHEN** 用户关闭显示开关后再开启
- **THEN** 所有窗口的超级键和相关浮层先消失，恢复后仍可查看存活会话中保留的记录，不重建终端或向 PTY 发送命令。

#### Scenario: 保存与跨窗口同步

- **WHEN** 用户修改显示开关并重新打开应用，或已有其他窗口存活
- **THEN** 本机偏好继续生效，存活窗口同步显示；未设置或值无效时默认显示。

#### Scenario: 保存失败

- **WHEN** 本机偏好存储不可写
- **THEN** 开关保持原值，设置中显示可理解的错误，不报告保存成功。

### Requirement: 复制成功的按钮反馈

系统 SHALL 在剪贴板写入成功后，仅将对应复制按钮显示为“已复制”，不额外显示成功通知或成功提示段落。行尾直接复制与详情复制均适用；失败不显示成功状态，保留内容和重试能力。

#### Scenario: 复制成功

- **WHEN** 用户点击行尾或详情中的复制按钮且剪贴板写入成功
- **THEN** 对应按钮显示“已复制”，不打开额外界面或显示成功 toast，仍可再次复制。

#### Scenario: 复制失败

- **WHEN** 剪贴板写入失败
- **THEN** 不将按钮显示为“已复制”，提供错误反馈并保留输出供重试。
