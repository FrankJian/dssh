# Proposal

## Why

用户在分配局域网 IPv4 地址前，需要按网段查看现有占用情况。当前工具箱只有离线地址计算和命令速查，缺少本机主动探测及逐地址结果展示。

## What Changes

- 工具箱「运维」增加「IP 地址检测」，接入现有目录、搜索与命令面板。
- 从当前电脑扫描用户输入的 IPv4 CIDR 网段或起止地址，按数字顺序展示地址网格、进度与结果详情。
- 红色表示发现在线或占用证据，绿色表示本次完整探测未发现占用，黄色表示无法确认；等待、扫描中及取消后未完成的地址使用中性状态。
- 通过 ICMP 与同链路邻居发现提高覆盖率，展示探测依据、可用的 MAC、响应耗时和检测时间。
- 支持开始、停止、重新扫描、按状态筛选及复制地址；结果保存在当前窗口内存中。
- 为没有响应、权限不足、网络不可达、缓存邻居信息、网络地址和广播地址提供可区分的结果。

## Capabilities

### New Capabilities

- `lan-ip-scan`：本机 IPv4 网段探测、占用证据分类、可取消任务、窗口归属及工具箱结果展示。

### Modified Capabilities

无。

## Impact

- 前端新增工具页、扫描 DTO 与服务，复用共享按钮、选择菜单、分段筛选和语义状态色。
- Rust 增加扫描管理器与开始、取消命令，注册到 Tauri；处理窗口关闭、并发、超时和子进程回收。
- 平台适配覆盖 Windows 与 macOS，评估已有依赖是否足以调用 ICMP 与邻居发现能力；实际依赖由实现阶段的平台验证决定。
- 主动探测由用户点击开始触发。探测结果提供选址参考，DHCP 租约、保留地址与暂时离线设备仍需用户结合网络管理记录判断。
