# Design

## Context

动机见 [proposal.md](proposal.md)。现有 `src/tools/catalog.ts` 管理工具入口，`src/services/` 封装 Tauri IPC，Rust 工具命令目前只涉及哈希与图片保存。主动扫描需要独立的任务管理、平台适配与窗口生命周期处理。

扫描后端、工具目录入口与页面已实现。自动化回归和 macOS 回环探测的结果见文末；真实局域网、Windows 与界面原生验收仍待完成，不能据此认定达到发布门槛。

## Goals

- 将占用证据、无响应及执行错误分别建模，避免在网络诊断失败时输出绿色地址。
- 扫描由本机执行，结果归属发起窗口，支持取消和工具切换后继续查看。
- 地址网格能够覆盖日常 /24 以及较小的子网，较大范围使用有界工作队列。

## Decisions

### 1. 范围解析与界面

输入支持 CIDR 和起止地址两种模式，通过共享分段控件选择。发现到可用的本机 IPv4 接口时提供接口与网段建议，用户仍需点击开始。多网卡机器展示所选来源，扫描目标使用实际路由；跨链路目标的邻居信息只展示可确认的目标证据。

后端是范围校验的权威入口。CIDR 的主机位被规范化并显示；/0–/30 的网络和广播地址在结果中标为保留，/31 与 /32 保留各自的候选端点。显式范围按用户指定地址生成，缺少子网信息时不自行断言 .0 或 .255 是保留地址。拒绝多播、未指定及有限广播地址作为探测目标。扫描预算按展开范围计算，在分配大型数组前应用 4096 个候选上限。

布局使用对齐的顶部输入工具栏、进度与状态筛选、地址网格和详情区。动作采用带悬停文字的共享图标按钮，结果使用语义 success、danger、warning 与 neutral token，并配文字或图标。绿色「未发现占用」旁的必要说明直接说明 IP 分配的判断局限。

### 2. 证据与平台适配

每个结果独立保存探测状态、证据来源及检测时间。红色证据包括目标成功 ICMP 回复、本机接口地址、当次确认的同链路 IP/MAC；无法证明新鲜度的缓存进入黄色「无法确认」。网关和路由设备的 MAC 不能被填为远端目标 MAC。代理 ARP 可能反映代答，应在依据中保留识别信息，不能由 MAC 推断设备身份。

Windows 优先使用系统 ICMP API 及 IP Helper 邻居能力，明确检查 ICMP 回复状态；同链路 ARP 请求须绑定适当来源地址，操作错误与正常未响应分开。macOS 采用系统 ICMP 能力或固定路径的标准 ping，结合邻居表，输出解析固定 locale；实际可用接口先通过普通用户原生验证确定。若使用系统子进程，参数逐项传递，地址由 IPv4 解析器生成，执行器具备取消、超时和子进程回收。

首轮采用最多 32 个并发目标、每目标最多两次 ICMP 探测、单次约 800ms 的超时；平台调用另设完成边界，防止邻居解析长时间占用工作线程。具体并发通过 /24 测量调整，并维持同一资源上限。启动任务前检查平台能力；系统性失败直接报告，避免逐地址重复失败后出现大片绿色结果。

扫描通过正常网络协议获取响应。没有响应的地址仍可能属于休眠、隔离或未对本机可见的设备，DHCP 保留和租约也需要网络管理记录参与判断。标准依据见文末 RFC 5227。

### 3. 任务与 IPC

新增 `network_scan` 业务管理器，命令层只负责窗口归属、解锁状态、参数校验和错误规范化。开始扫描请求含范围及客户端任务标识，后端以调用窗口标签绑定所有权；取消请求只能取消本窗口对应任务。每个窗口单任务，重复开始返回可读错误或在旧任务清理后开始。

进度通过带 scanId、序号的窗口定向事件或 IPC Channel 增量传递；前端按 scanId 接收，合并状态时忽略已取消或旧任务事件。分批更新采用约 100–200ms 的合并间隔，避免为每个探测反复渲染整个网格。总数、已完成数及各类计数由同一状态集合计算。

取消先停止调度，再取消可中断 I/O 并回收运行中的子进程；不可立即中断的系统调用须受短超时约束。窗口销毁调用管理器按 owner 取消。完成、失败和取消各有唯一终态；重复取消幂等。切换活动页只影响显示，关闭窗口才清除所属任务与内存结果。

### 4. 地址分配结果语义

| 状态 | 颜色 | 判断条件 |
| --- | --- | --- |
| 检测到占用 | 红 | 存在本次有效响应或本机地址证据 |
| 未发现占用 | 绿 | 计划探测完整执行、无有效响应且无执行错误 |
| 无法确认 | 黄 | 权限、路由、平台能力、解析错误或仅有未核实缓存 |
| 待扫描 / 扫描中 / 未完成 / 保留 | 中性 | 相应调度或地址状态 |

保留网络地址和广播地址时不发送探测；停止后未完成地址保持中性。地址详情对齐展示原始依据，不能由颜色推断租约或保证可分配性。

## Risks / Trade-offs

- ICMP 过滤或设备离线会使绿色结果缺少占用证据，通过准确标签、邻居探测与必要的 DHCP 核对说明表达局限。
- 多网卡、VPN 和跨路由网段可能改变可见性，展示来源和方法，跨链路不使用下一跳映射推断目标 MAC。
- 取消期间阻塞平台 API 仍可能短暂运行，为调用设置完成期限，保持句柄存活到调用结束，并阻止其迟到结果污染新任务。
- 系统权限和本地网络授权可能导致探测失败，映射为无法确认，并在 Windows/macOS 普通用户安装包上验收。

## Migration Plan

新增工具目录和 IPC，扫描数据使用窗口内存，无数据库迁移。发布门槛为回归通过及 Windows/macOS 原生验收；通过任务清单分别记录实现与实机状态。

## Implementation and verification

2026-11-26，macOS 27.2.1 / Apple Silicon。

- 已实现 `network_scan` 管理器与窗口定向 IPC Channel。每窗口一项扫描，最多 32 个目标并发、150ms 批量进度；输入与结果只在当前窗口内存保存。停止后等待工作项收尾，未完成项保留中性状态。准备阶段停止同样返回取消终态。
- macOS 使用 `getifaddrs` 读取接口，固定路径 `/sbin/route` 核对路由，`/sbin/ping` 两次 ICMP，`/usr/sbin/arp` 读取目标邻居。所有参数独立传递，固定 C locale，子进程有 4 秒总超时、取消和 kill-on-drop。仅接受目标地址的 ICMP 回复；只在路由与同链路接口均匹配时使用目标 MAC。基线中已经存在的 MAC 无法证明新鲜度，单独作为黄色结果。
- Windows 实现 `GetIpAddrTable`、`GetIpNetTable`、`GetBestRoute`、`IcmpSendEcho2Ex` 和 `SendARP` 适配。ICMP 检查成功状态与目标地址，超时与系统错误分开；ARP 限定直接路由及匹配的来源接口。阻塞 API 在有界工作项中运行，取消后不再调度，保留任务与句柄到调用结束。此环境未安装 Windows 编译目标，Windows 编译、普通用户 API 行为与 ARP 耗时尚未验证。
- 工具页复用共享按钮、分段选择与下拉控件，新增布局和颜色只引用语义 token。支持 CIDR / 起止地址、接口建议、显式开始、停止、重新扫描、筛选、详情、复制及方向键移动。已有 ToolsWorkspace 保留访问过的工具组件，因此切页不卸载扫描页面。目录与命令面板共享 `ip-scan` 入口。
- 自动化覆盖地址范围、保留地址、规模边界、证据优先级、MAC 过滤、ICMP 输出与参数传递、进程取消、并发上限、混合结果排序与计数、任务归属和迟到进度隔离。`cargo test --lib native_ -- --ignored` 中两项扫描测试在普通用户权限下通过，实际调用系统 ping 到 127.0.0.1，并通过 IPC 调度器扫描本机接口。127.0.0.2 在此机器上没有回复，不能假设整个回环网段都在线；冒烟目标已改为实际配置的 127.0.0.1。
- 当前会话浏览器连接不可用，未进行页面截图和交互验收；仅完成类型、构建及状态模块回归。主窗口/独立窗口、宽窄布局、深浅色和自定义配色的实际观察仍待补充。
- 未对真实局域网发起扫描；离线、DHCP、ICMP 过滤、ARP 代理、多网卡及权限拒绝场景仍需原生设备对照。绿色只代表本次完整探测未发现占用，不能证明可分配。实现完成与发布验收保持区分，未完成项继续保留在 tasks.md。

### 页面排版跟进（2026-11-26）

将进度、计数及筛选收进统一概览区；地址卡片使用一致的最小高度与完整 IPv4 所需列宽，减轻状态底色和边框，选中与键盘焦点使用内描边。详情顶部突出所选 IP 与状态，余下字段采用固定标签列和可换行值列。宽布局的网格与详情共享高度边界，窄布局自动上下排列，筛选后的网格按内容收紧。

本轮通过临时浏览器模拟页观察浅色宽布局、深色 420px 窄容器，检查完整 IP 展示、卡片/详情对齐、选择切换、方向键和黄色状态筛选；未发出真实扫描请求。预览发现 IP 列宽不足并已修正，窄布局筛选后多余留白也已修正并复看。临时页面已移除。类型检查、生产构建及工具回归继续执行，结果记在 tasks.md。自定义配色、减少透明度、原生主/独立窗口与跨平台视觉仍未验收。

### 简洁结果视图（2026-11-26）

结果概览区增加共享 SegmentedControl，在默认卡片与简洁视图之间切换。简洁项仅显示完整 IP 与状态圆点，使用中性底板；状态文字继续出现在悬停说明、无障碍名称和详情中。两种视图使用同一组结果按钮、筛选及选中状态，仅切换呈现，不重新扫描。显示模式保存在组件内存，窗口关闭后清空。

临时模拟页验证了浅色宽布局、深色 420px 容器、圆点状态色、完整地址、方向键选择、筛选及切回卡片后保留已选地址和详情。没有发起真实网络扫描；临时页面已移除。原生双窗口、自定义配色及平台探测的验收范围沿用上述限定。
