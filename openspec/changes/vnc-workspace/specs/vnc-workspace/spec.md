# VNC workspace spec delta

## Purpose

在 Duo SSH 工作台内提供有明确传输和安全边界的 VNC 查看器。连接配置、远端认证、渲染能力和日常输入分别管理，优先 SSH 隧道，凭据只在后端处理；此规格是未实施的目标，不表示当前软件已经支持 VNC。

## ADDED Requirements

### Requirement: 独立配置和秘密生命周期

系统 SHALL 为 VNC 提供独立配置与运行会话，明确主机和 1–65535 端口（默认5900），SSH 隧道引用已有配置且目标从网关视角解析。读取配置只返回 hasPassword；保存密码必须使用可靠系统凭据存储，否则禁止保存并允许本次瞬时输入。导入导出遮罩规则不能把占位符当作密码。

#### Scenario: 隧道来源被删除

- **WHEN** VNC 配置引用的 SSH 配置已删除
- **THEN** 标记隧道来源失效并允许修复，不级联删除 VNC 配置，不转为不安全直连。

### Requirement: 凭据不进入渲染层

系统 SHALL 在后端完成远端认证，再提供短期、不可持久化且绑定所有权的本地渲染连接能力；VNC 密码和挑战响应不得交给 WebView、日志、AI、状态事件或测试 fixture。后端桥必须验证本地端点的来源、能力有效期与会话归属。

#### Scenario: 非所属视图请求桥连接

- **WHEN** 页面使用过期或不属于自身会话的渲染能力
- **THEN** 拒绝连接，不暴露远端流或凭据，不影响其他会话。

### Requirement: 传输策略和服务器身份

系统 SHALL 优先经共享 SSH 传输与既有主机密钥校验连接。受限无 TLS 直连在保存及每次连接时明确确认风险，不默认自动重连或同步剪贴板；只允许策略明确许可的安全类型。TLS/X.509 阶段校验链、主机名和 pin，不复用 SSH known_hosts 或因协商失败静默降级。

#### Scenario: 服务器只提供弱安全类型

- **WHEN** 服务器没有提供配置允许的安全方式
- **THEN** 以安全策略错误失败，不自动降为明文或跳过服务器身份验证。

### Requirement: 会话关闭和资源隔离

系统 SHALL 在标签关闭、断开、配置更改、隧道失效、独立窗口关闭或桥断开时撤销渲染能力并释放所属资源；不关闭共享 SSH 传输上的其他终端或 SFTP。首版默认手动重连；后续恢复必须限次、可取消且认证失败停止。

#### Scenario: 用户关闭 VNC 标签

- **WHEN** 同一 SSH 传输还有终端和 SFTP 正在运行
- **THEN** 仅关闭该 VNC 的远端流、桥、渲染与通道租约，其他会话继续运行。

### Requirement: 输入和剪贴板权限

系统 SHALL 提供只读、缩放/裁剪、全屏、键盘重新捕获、刷新与 Ctrl-Alt-Del；只读在客户端阻断上行输入。剪贴板双方向开关默认关闭，正文仅短暂驻留内存，不写历史或 AI。VNC 不加入终端分屏树，AI 不得借界面动作获得桌面输入权限。

#### Scenario: 只读会话收到用户键盘输入

- **WHEN** 当前 VNC 会话启用 view-only
- **THEN** 不发送键盘或指针上行，即使焦点位于远程画布。

### Requirement: 分阶段发布门槛

系统 SHALL 在凭据不出渲染层的 Phase 0 可行性验证、安全存储验证及两平台真实服务器矩阵达标后才发布对应能力；不能以库声明或模拟测试替代互操作结果。Phase 5 的 repeater、额外认证、能力优化、导入与录制是可选范围，不阻塞首版。

#### Scenario: 密码安全桥未获证明

- **WHEN** Phase 0 尚不能证明密码不进入 WebView
- **THEN** 不发布保存密码能力或进入正式密码实现，仅保留明确受限的研究路径。
