# 首屏按需加载

## Why
用户报告尤其 Windows 启动慢。首轮生产构建依赖分析显示入口静态 JavaScript 约 1.80 MB（UTF-8），包含 xterm/WebGL、编辑器、设置、SFTP 和对象存储等未打开功能；现有 LazyTerminalView 被静态 terminalRegistry 的运行时导入抵消。尚无 Windows 冷启动计时证据。

## What Changes
- 终端注册表保留轻量状态和同步生命周期接口，首次显示终端前再加载 xterm/插件构造器及 CSS；共享加载请求，失败可重新尝试。
- 非首屏功能界面懒加载，设置分类等导航元数据独立保留，加载失败局部反馈并可重试。
- 增加生产静态依赖预算回归和前后对比证据。不改凭据、锁屏、主机身份校验、数据库迁移或远端命令批准；不自动连接或提前加载全部重模块。
