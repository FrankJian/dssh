# Native window material spec delta

## Purpose

为希望窗口透出桌面背景的用户提供可选原生材质，并将其与应用内 CSS 玻璃、应用配色、终端背景区分。功能必须按平台能力、安全降级和窗口行为验证逐步开放；本变更仍待实施，默认关闭，不改变当前界面视觉方向。

## ADDED Requirements

### Requirement: 默认关闭和独立偏好

系统 SHALL 提供 off/window 两档原生材质偏好，默认 off，强度 low/medium/high 默认 medium；只作用桌面透视，不能借此关闭现有应用内材质或替换应用配色。设置在本机保存，主窗口与独立工作台同步，新建窗口读取当前偏好。

#### Scenario: 停用原生材质

- **WHEN** 用户从 window 切换到 off
- **THEN** 清除系统窗口材质，保留应用内表面、当前应用颜色与终端方案。

### Requirement: 能力感知与降级

系统 SHALL 根据后端探测的平台能力判定是否可用；Windows 10、无合成能力或不支持的 macOS 环境回退 off。减少透明度时不施加原生材质并保留实色 fallback；不支持 CSS backdrop-filter 仅影响应用内 fallback，不错误改变系统材质能力判定。

#### Scenario: 偏好在不支持的平台恢复

- **WHEN** 保存的 window 模式加载到不支持的平台
- **THEN** 渲染为 off，并在设置禁用不可用选项且说明原因，不呈现失效开关。

### Requirement: 窗口行为和性能门槛

系统 SHALL 在主窗口与独立窗口验证拖拽、缩放、最大化、贴边、任务栏/Dock、多 DPI 与启动闪烁；运行期材质切换不要求重启的目标须先经 Phase 0 证明。若透明创建破坏窗口行为，应修订切换方案或不发布，不以丢失操作能力换取透视效果。

#### Scenario: 透明窗口可行性失败

- **WHEN** Phase 0 发现不可接受且无缓解的窗口行为回归
- **THEN** 不进入受影响窗口方案的发布，记录并修订为保守方案后再继续相关阶段。

### Requirement: 内容表面与无障碍隔离

系统 SHALL 仅调整窗口底板与稳定 chrome，终端、编辑器正文及高频滚动内容保持自身不透明度语义，不叠多层无界磨砂；按实际合成背景校准文字、图标和状态对比度。材质与主题切换不能改变会话、输出、分屏或内容颜色配置。

#### Scenario: 切换材质时终端运行

- **WHEN** 用户在持续输出的终端旁切换原生材质或强度
- **THEN** 终端继续工作且正文、选区和背景设置保持，无重置或重连，性能回退有实际记录。

### Requirement: 平台增强与分发限制

系统 SHALL 使用经过验证的平台材质与后端命令，主/独立窗口一致；额外权限与窗口能力更改完整重启后验收。默认路径不依赖未保障的私有材质，Phase 6 的 macOS 私有效果单独评审、可降级且不作为发布门槛；分发资格影响须明确记录。

#### Scenario: 可选私有材质不可用

- **WHEN** 可选平台增强在系统更新后失效
- **THEN** 回退已验证的公开材质或 off，不阻塞默认应用界面及现有 CSS 玻璃。
