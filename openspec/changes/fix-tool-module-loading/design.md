# 设计

统一 lazyTool 工厂包装工具目录中所有懒加载模块。每次显式重试创建新的 React.lazy 实例，绕开 React 对拒绝 Promise 的缓存；局部边界放在 Suspense 外，错误时显示简短中文反馈和共享 Button，内部错误只记录开发控制台。其他工具仍挂载，切换工具或主功能不受失败影响。不自动刷新整个应用，不自动循环重试。

测试服务使用独立 Vite 缓存，SSR 回归使用临时缓存并在关闭后清理。独立 UI 回归服务器使用 Vite 的专用 mode，避免改动正在运行的日常开发配置。开发模式继续预优化 JSON 入口依赖。

验证需要模拟一次加载失败再恢复，以及失败后仍可切换工具/主功能；源码检查或构建不能证明原始 Safari/WebView 故障根因。原始失败模块 URL 和响应尚未捕获，须如实记录局限。
