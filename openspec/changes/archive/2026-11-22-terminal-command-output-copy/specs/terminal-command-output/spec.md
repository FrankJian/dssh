# 命令输出记录

## Purpose

让用户从当前终端最近执行的非交互且已结束命令中定位、预览和复制对应输出，减少滚动与手动选区操作。记录按每次执行隔离并有界保留，仅用于当前会话中的便捷取用，不作为完整日志或跨重启历史。

## ADDED Requirements

### Requirement: 可复制命令的资格与边界

系统 SHALL 仅在 shell 提供完整 OSC 133 命令边界标记且能验证可见命令文本时，为已结束的非交互命令提供记录，包括执行失败但正常返回提示符的命令。运行中、交互程序、认证输入和边界不明的片段 SHALL 不进入可复制列表；不得仅因输出暂时静默就判定结束。

#### Scenario: 普通命令完成与重复执行

- **WHEN** 同一普通命令执行两次且均已结束
- **THEN** 两次执行分别生成记录，分别关联各自输出，按执行时间从新到旧显示。

#### Scenario: 命令失败

- **WHEN** 非交互命令报错并已可靠确认结束
- **THEN** 其终端错误输出可查看和复制，不因失败而丢弃；不在没有依据时推断退出码。

#### Scenario: 运行中和交互程序

- **WHEN** 命令仍在运行、进入全屏交互程序，或要求密码、验证码及交互回答
- **THEN** 该次执行不作为已完成的非交互记录提供，后续交互输入不被当作独立命令记录。

#### Scenario: 无法可靠分段

- **WHEN** shell 缺少完整边界标记，或嵌套 shell、网关菜单导致命令与结束边界不明确
- **THEN** 不把猜测出的片段作为可复制的完成记录，也不自动向终端执行探测命令或修改 shell 配置。

### Requirement: 每终端有界内存保留

系统 SHALL 为每个终端独立保留最近 20 次符合资格的执行，超出数量淘汰最早记录。记录和捕获中的输出 SHALL 有明确容量上限，仅存内存；关闭终端或重启应用后不恢复，重连后的新 shell 不混入旧 shell 的执行片段。此记录不改变滚动历史和流控设置的既有语义。

#### Scenario: 容量淘汰与隔离

- **WHEN** 一个终端产生第 21 条符合资格的完成记录
- **THEN** 淘汰该终端最早记录，其他终端的记录保持不变；同一命令的多次执行分别计数。

#### Scenario: 切换页面与关闭

- **WHEN** 用户切换标签或重新挂载同一存活终端视图
- **THEN** 其记录仍可用；关闭该终端后，记录及未完成捕获被释放且不写入持久化存储或日志。

#### Scenario: 显示历史淘汰

- **WHEN** 终端滚动历史淘汰旧行
- **THEN** 已独立保留的命令输出按自身容量规则继续可用，不能通过调大历史设置恢复已丢弃输出。

### Requirement: 输出内容与不完整提示

系统 SHALL 以可选择的纯文本展示和复制同一份保留输出，排除命令回显、shell 提示符及终端控制序列，保留有意义的换行和列间空白。无输出时显示空状态且禁用复制。达到容量上限或遇到已知投递缺口时 SHALL 明确标记不完整，不能拼接缺口两侧为完整结果。

#### Scenario: 普通彩色输出

- **WHEN** 命令输出包含 ANSI 颜色和多行表格
- **THEN** 预览、弹窗和剪贴板使用同一份无控制序列文本，保留表格空白和实际换行，不引入终端宽度导致的额外硬换行。

#### Scenario: 超长输出

- **WHEN** 单次输出超过保留容量
- **THEN** 有界保存并在列表、预览和弹窗中标记“输出已截断”，复制仅复制保留文本，不把状态说明混入输出。

#### Scenario: 过载或断线缺口

- **WHEN** 捕获期间输出过载暂停或连接中断，无法确认该次执行的完整输出及结束边界
- **THEN** 丢弃未确认完成的捕获，不将其伪装成完整完成记录；已完成记录不受新缺口污染。

#### Scenario: 无输出命令

- **WHEN** 符合资格的命令结束且没有输出
- **THEN** 列表保留该执行，预览及弹窗显示“无输出”，复制操作禁用且不覆盖剪贴板。

### Requirement: 魔法工具入口与最近记录列表

系统 SHALL 在对应终端 pane 提供带可访问名称的魔法工具按钮，悬停展开功能项并支持点击和键盘等效操作。首版功能项为“复制命令输出”，激活后展示当前终端记录及执行时间；无记录时呈现空状态。记录行尾 SHALL 提供直接复制输出的独立按钮，不触发详情弹窗或向 PTY 发送输入。

#### Scenario: 分屏与直接复制

- **WHEN** 用户在某分屏的魔法工具中打开列表并点击一条记录的复制按钮
- **THEN** 只复制该分屏终端中该次执行的保留输出，不打开弹窗、不切换目标、不执行命令。

#### Scenario: 键盘访问与空列表

- **WHEN** 用户通过键盘聚焦并打开魔法工具，当前终端没有可用记录
- **THEN** 可访问“复制命令输出”及其空状态，Escape 可关闭浮层并将焦点返回触发控件。

### Requirement: 悬停预览与只读详情

系统 SHALL 在命令行持续悬停短暂延迟后预览有限行数的输出，键盘聚焦记录时提供等效预览。点击记录 SHALL 打开共享风格的只读弹窗，展示命令、执行时间、输出及不完整状态，支持文本选择、滚动、复制输出和关闭。预览与弹窗不得向远端发出读取或重执行命令。

#### Scenario: 预览后查看

- **WHEN** 用户悬停或聚焦一条记录后点击该记录
- **THEN** 先显示有限内容预览，再在弹窗显示该记录保留的输出；弹窗复制与行尾直接复制结果一致。

#### Scenario: 复制失败与关闭

- **WHEN** 剪贴板写入失败或用户关闭详情
- **THEN** 失败时显示可理解的错误并保留内容供重试；关闭时恢复合理焦点，不将界面按键误传入终端。

#### Scenario: 多种外观与窄布局

- **WHEN** 用户在深浅外观、自定义配色、减少透明度或窄分屏中打开列表、预览和弹窗
- **THEN** 控件、状态和焦点清晰可读，浮层不超出窗口，输出区可滚动且不因模糊影响阅读。


### Requirement: 用户确认后启用本次 SSH 会话识别

系统 SHALL 为未具备边界标记的普通 SSH 终端提供“启用本次会话的命令识别”，支持用户选择 Bash/Zsh 并在确认后向同一 shell 发送内置临时集成脚本。脚本 SHALL 不写配置文件、不重新执行历史命令、不覆盖冲突 hook，重复启用不叠加。连接、重连及查看记录 SHALL 不自动发送脚本。

#### Scenario: 启用后执行 ll

- **WHEN** 用户在普通 SSH 的空白 Bash/Zsh 提示符上选择 shell 并确认启用，随后执行并结束 `ll`
- **THEN** 系统检测到边界标记后显示识别可用，并提供该次 `ll` 的输出记录，安装脚本自身不成为命令记录。

#### Scenario: 取消确认

- **WHEN** 用户打开启用对话框后取消或关闭
- **THEN** 不向终端发送任何脚本，也不改变远端配置或本次识别状态。

#### Scenario: 确认失效

- **WHEN** 确认期间出现新输入/输出、重连、关闭、锁屏或窗口归属变化
- **THEN** 拒绝发送，提示用户重新检查终端并确认，不把批准转移到另一终端或 shell。

#### Scenario: 不支持或冲突

- **WHEN** 选择的 shell 不匹配、已有无法安全共存的 hook、终端正在认证/交互程序中，或未收到启用确认标记
- **THEN** 明确显示失败或未启用，保留原有 shell 行为且不自动重试。

### Requirement: 命令识别状态与空列表可区分

系统 SHALL 区分未检测到识别、启用中、已检测到识别及启用失败。没有记录时，未检测到识别的普通 SSH 终端 SHALL 展示启用入口；具备识别的终端 SHALL 显示暂无可复制输出。状态只保留于当前 shell 世代，不因本机记忆在重连后自动安装。

#### Scenario: 普通 SSH 没有标记

- **WHEN** 用户执行命令后打开列表，当前 shell 尚未提供边界标记
- **THEN** 呈现“尚未启用命令识别”及显式启用入口，不仅显示笼统的无记录信息。
