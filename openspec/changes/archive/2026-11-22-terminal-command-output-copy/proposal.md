# Proposal

## Why

用户复制已执行命令的输出时，需要向上滚动并手动选择，容易遗漏边界或混入提示符。提供按执行记录查找、预览和复制输出的入口，减少重复选择操作。

## What Changes

- 首版仅在 shell 提供完整 OSC 133 命令边界标记时生成记录；无标记终端不记录；新增经用户确认的本次会话 Bash/Zsh 临时集成入口，不修改 shell 配置文件。

- 在各终端 pane 提供魔法工具按钮，悬停展开功能项，同时支持点击和键盘访问；首版只有“复制命令输出”。
- 列出当前终端最近 20 次非交互且已结束的命令，按执行时间从新到旧排列，重复命令分别记录，失败但已结束的命令同样可用。
- 悬停命令可预览输出，点击命令打开只读弹窗；列表行尾和弹窗均提供复制输出按钮。
- 记录只存内存，关闭终端即清除；单次输出有容量上限，截断或输出缺口明确呈现，不宣称完整。
- 输出复制排除命令回显、提示符和终端控制序列，不引入自动执行、远端日志收集或磁盘持久化。

## Capabilities

### New Capabilities

- `terminal-command-output`: 每次非交互命令执行的有界输出记录、最近记录列表、预览和复制，以及会话隔离与生命周期。

### Modified Capabilities

无。现有 `terminal-output` 的滚动历史、投递流控和过载恢复语义保持不变；新增记录独立受限，不扩展现有历史为完整日志。

## Impact

- 前端终端输入/输出跟踪、会话生命周期、终端 pane 入口及共享浮层、Dialog、剪贴板反馈。
- 预计复用 `commandActivity.ts`、`terminalRegistry.ts`、`useTerminalSessions.ts` 的事件基础，但不直接复用会去重且持久化的命令补全历史。
- 需验证普通 SSH、本地终端和 JumpServer 场景的识别边界，维持现有流控性能、窗口归属及认证输入保护。
- 默认不新增依赖或持久化迁移；如跨窗口交接需要契约扩展，必须保持 Rust DTO、TypeScript 类型及服务层一致。
