# Design

## Context

动机见 [proposal.md](proposal.md)，行为契约见 [命令输出规格](specs/terminal-command-output/spec.md)。本变更跨越输入识别、输出流、会话生命周期和浮层交互，因此需要设计产物。

现有 `TerminalCommandActivityTracker` 使用 OSC 133 标记及提示符回退识别运行状态，但仅返回 idle/running，不能直接证明某次执行的输出范围。`CommandInputTracker` 校验可见回显并排除认证输入；现有补全历史受补全开关控制、会去重且存于 localStorage，不适合作为此次记录来源。终端实例可跨组件挂载保留，输出有独立 ACK、过载暂停和有界回放机制。

## Goals / Non-Goals

**Goals:**

- 将已可靠识别的执行转换为稳定、只读的输出记录，UI 不再依赖滚动区位置。
- 在捕获期间同样限制内存，不阻塞输出解析、ACK 或用户输入。
- 将记录归属于终端会话及 shell 世代，避免标签、分屏、窗口或重连后的内容串用。

**Non-Goals:**

- 不提供完整日志、跨重启记录、交互程序录屏、运行中快照或历史命令重执行。
- 不自动改写远端 shell 配置文件，不未经确认注入执行探针，不把提示符推断包装为所有 shell 都精确支持。
- 不调整补全开关、补全历史保存规则或现有显示历史设置。

## Decisions

### 1. 独立的会话内记录存储

记录由会话级内存存储持有，UI 订阅快照，不存于组件局部状态或补全历史。每条记录包含独立执行 ID、sessionId、shell 世代、命令文本、执行起始时间、单调排序序号、完成时间、保留输出及截断状态。退出码仅在可靠标记提供时记录。

每终端最多 20 条完成记录，另有至多一条捕获中的候选。采用每次最多 1 MiB UTF-8 纯文本的实现初值，保留开头前缀，超出后停止追加正文但继续解析生命周期。完整记录与候选总正文最多 21 MiB UTF-8 等价值；JS 字符串、索引和渲染开销需单独测量，不能把此数字宣称为 RSS 上限。预览只取前 8 行，超长单行也限制显示长度，不复制额外大文本供悬停使用。

切换标签、改变主题或重新挂载不清除记录；关闭会话释放全部状态。重连切换 shell 世代，清除旧记录与候选，防止同 sessionId 重用时混入旧执行。移窗如延续同一存活会话，随既有受归属约束的交接通道传递有界完成记录；取消旧世代的捕获并在新窗口重新等待可靠边界，不从原始回放猜测补建记录。不引入全局广播或磁盘中转；若需新增交接 DTO，三层契约同步更新。

备选：仅保留 xterm 行号/marker 会随 scrollback 淘汰失效；复用补全历史会丢失重复执行并改变持久化语义，因此均不采用。

### 2. 独立识别执行，保守处理交互和未知边界

复用现有跟踪器的解析经验，新增面向记录的生命周期事件，不改变标签运行指示原有启发式行为。捕获不依赖命令补全开启。输入只能作为候选线索，命令文本必须与实际可见回显或可靠 shell 元数据对应，不能仅按键盘输入保存秘密。

优先采用完整、顺序一致的 OSC 133 提示符/命令开始/结束边界；跨输出包保留解析状态。首版要求完整的 OSC 133 A/B/C/D 顺序及可见命令回显，无标记或顺序不完整时不生成记录。提示符推断仅保留用于原有运行指示，不用于本功能；静默超时不作为完成依据。此兼容范围调整已经用户确认。

执行期间进入 alternate screen、出现认证/交互提示、命令运行期收到用户回答、嵌套 shell/网关上下文无法确定、Ctrl+C 或流中断均使候选失效；重新同步到可靠 shell 提示符后才开始下一次。命令名称及常见交互启动方式只能辅助排除，不能单凭名称或“没有 alternate screen”证明非交互。普通失败返回提示符可形成记录，不能把交互过程中输入的回答、密码或菜单选项当作新命令。

该策略选择漏收不确定记录，避免误把其他输出和认证输入归入命令。首版兼容矩阵必须实际覆盖本地与 SSH shell、JumpServer 菜单和资产 shell；不支持的上下文保留普通终端功能，列表自然为空，不承诺任意自定义 shell 都可识别。

### 3. 纯文本抽取与流控并行

只消费已按序接收的输出，不另建 SSH exec 读取输出，也不在用户打开菜单时读取 scrollback 作为替代。使用有界的增量终端文本抽取路径处理 ANSI、跨包转义、CR/退格和换行；不能只对原始字节正则删除颜色码，因为进度刷新及光标重写会留下错误结果。输出区保留逻辑换行和空白，排除提示符及命令回显；无法正确归一化的复杂光标控制使候选失效。

复用现有终端解析能力的可行性在实现任务中验证；若使用独立解析缓冲，应显式限制其行长及内部存储，不能正文已截断但解析器仍无限增长。捕获路径不向远端响应控制查询，不拦截输入、不阻塞 ACK；完成时才发布新记录，避免每个输出包触发 React 列表渲染。输出截断后仍需解析结束和交互标记，保证长命令最终能收束。

发生暂停、缺口、重置或断线时取消未确认完成的候选，不拼接恢复快照；已完成记录独立保留，重连按世代清理。初始回放只可恢复当前提示符/输入状态，不建立已提交候选或重复生成执行记录；完成记录仅来自 live 提交与执行边界。

### 4. 渐进展开的终端工具

入口位于各 pane 的角落，避开滚动条和输入区，采用现有 Icon 与透明工具按钮，不使用装饰性大按钮。悬停、点击、键盘打开功能菜单；首版单项“复制命令输出”，点击后展示最近列表。列表每行命令、时间和复制按钮，重复命令靠时间及执行 ID 区分。

记录行持续悬停约 300 ms 或键盘聚焦后显示小型只读预览，进入预览区域可保持显示；离开、Escape、切换记录和打开详情时及时关闭。弹窗复用共享 Dialog，正文近不透明、等宽、可选择和滚动，命令作为上下文展示；复制仅取输出，不混入命令、时间或截断提示。复制成功提供简短反馈，失败保留内容并允许重试。空输出禁用复制。

列表行查看与行尾复制使用独立交互控件，不能嵌套 button；操作浮层时不触发 TerminalView 的终端聚焦或把键盘输入透传 PTY。浮层锚定 pane 并在窗口范围内翻转/限制尺寸，窄布局保留操作顺序，弹窗关闭后恢复到触发控件。所有配色、焦点、减少透明度及动效沿用设计规范。

备选：始终展开列表会长期遮挡终端；只提供弹窗复制会增加日常操作，因此保留悬停预览和行尾直拷两个捷径。

### 5. 显式启用普通 SSH 会话的临时集成

用户测试普通 SSH 的 `ll` 时暴露出仅被动接收标记的可用性缺口。经用户确认，新增“启用本次会话的命令识别”：选择当前 Bash/Zsh，在共享 Dialog 中确认后，由后端发送固定的、只影响当前 shell 的脚本。脚本不写文件、不重启 shell、不重新执行已有命令，不在连接/重连/菜单展开时自动发送。

准备阶段只读，返回窗口归属内的目标与输入/输出版本；提交再次校验窗口归属、锁屏、会话状态、前台普通 SSH 类型、提示符及版本后原子入队，沿用现有输入版本和过期批准保护。认证提示、网关菜单、全屏程序及非空/未知提示符不自动处理。用户须先回到空白 shell 提示符。脚本只从后端内置资源选择，前端不能传入任意脚本文本。

Bash 保留原 PROMPT_COMMAND 的字符串/数组语义并在原 hook 前后插入结束和提示符处理；使用无冲突的 DEBUG trap 提供执行开始边界，统一支持 Bash 3.2 及以上版本。已有 DEBUG trap、functrace/extdebug 或冲突 PS0/只读配置时拒绝安装，避免覆盖用户逻辑。Zsh 以命名 hook 扩展既有 precmd/preexec 数组，保持提示符内容与原 hook；同一 shell 重复启用不叠加。旧版本/选错 shell/冲突给出可读失败状态。

安装脚本经单行安全编码发送，限制在 PTY 常见单行容量内；ready/error 标记只是功能状态，完成记录仍要求完整 A/B/C/D。未启用、启用中、已检测到标记和失败分别呈现，超时不宣称成功，安装脚本自身不进入复制列表。关闭/重连清除前端状态，远端 hook 随当前 shell 生命周期结束。

## Risks / Trade-offs

- 标记缺失、任意程序交互不可完全证明 → 只接纳有充分边界依据的记录，未知情形漏收；用交互与自定义提示符回归防止过度承诺。
- 多终端及长行造成内存放大 → 同时约束记录数、候选正文、解析器及预览尺寸，洪水场景测量实际开销与输入延迟。
- 终端格式复杂 → 测试 CR 刷新、换行、颜色、跨包转义及重写；不支持的复杂控制放弃记录。
- 输出可能含敏感业务内容 → 只在当前会话内存保留，不写日志、localStorage 或数据库，复制仅由用户显式触发；不声称关键词过滤能自动脱敏全部输出。
- 移窗交接放大载荷 → 仅向新归属窗口传递有界完成记录，确认旧窗口释放，检查取消和归属变化，验证传输期间内存峰值。

## Migration Plan

无数据库或用户配置迁移。实现后新增内存能力，原有命令补全及输出设置保持兼容；回退该功能不需要回滚持久化数据。实施验证和真实环境验收分别记录在 [tasks.md](tasks.md)，未验收平台不标为发布完成。
