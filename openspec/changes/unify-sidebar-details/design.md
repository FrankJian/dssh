# Design

## Context

见 proposal.md。App 已持有 `dssh.sidebar.collapsed`，但连接管理、工具箱、Artifactory 的导航位于主表面内，编辑器还持有独立的文件树可见状态。功能切换存在多个强制展开路径。当前工作区包含编辑器需求的在途实现，必须保留其模型、移窗与授权边界。

## Goals / Non-Goals

- 统一可见性和功能归属，复用各导航容器及宽度，不迁移其业务数据状态。
- 不控制右侧停靠、编辑器问题面板、SFTP 双栏正文或制品属性详情，不修改远端访问逻辑。

## Decisions

1. App 的折叠偏好为唯一状态；组件接收可见性，编辑器接受受控状态及显式展开回调。单独运行的编辑器保留非受控兼容入口，主工作台不再出现第二个折叠图标。
2. 当前表面优先于保留的 activity：编辑器和浏览器在 sessions 外壳内时分别归属编辑器/无详情，不回退显示会话树。使用纯上下文选择器集中描述映射，供导航按钮、App 与回归共用。
3. 功能图标只导航，不折叠、不自动展开。主动搜索/定位文件保留显式展开语义，并同步统一偏好。已有键盘开关、命令面板与编辑器拖窄折叠走同一入口。
4. 现有内置导航保持挂载并以 hidden 折叠，网格同时回收列宽；编辑器正文不因收起被卸载。窄宽度的临时布局适配不覆盖偏好。
5. 首位按钮采用现有线性侧栏图形和方向提示，独立的轻分隔、语义表面/圆角/焦点，不添加常驻说明；无详情表面禁用但保留用户偏好。

## Risks / Trade-offs

- 旧导航入口强制展开可能遗漏 → 检查所有折叠状态写入与每类活动矩阵，用回归覆盖导航/标签切换。
- 嵌入式导航折叠后空列或重复侧栏 → 各容器显式布局属性，并验证编辑器仅显示自己的导航。
- 隐藏目录导致搜索草稿丢失 → 保持容器挂载，隐藏时禁用相应扫描/交互；不卸载正文。
- 原生窗口/GPU/DPI 不能由浏览器验收代替 → 单独记录未验证边界，不宣称发布完成。

## 侧栏过渡补充

保留实际详情 DOM，用注册的数值 CSS 自定义属性驱动同构网格、宽度、间距和透明度，150ms 与现有外壳一致。使用 inert/aria-hidden 立即隔离交互，visibility 在关闭过渡结束后隐藏；减少动态效果时直接归零。外壳通过显式可见性分离内容存在性，拖动期间取消插值；终端文件树过渡期间暂停中间尺寸 fit，结束后统一适配。
