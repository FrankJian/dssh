# Proposal

## Why

当前功能图标混合页面切换与侧栏折叠，部分功能拥有独立导航栏，导致收起状态在切换功能时被重置。用户需要固定首位、行为一致的侧栏详情开关，并让当前功能只展示对应的导航详情。

## What Changes

- 左侧活动栏首位增加不可被功能图标设置隐藏的详情开关，提供展开/收起图形、名称、键盘焦点和展开状态。
- 统一控制会话、连接管理、SFTP、S3、Artifactory、工具箱及活动编辑器的左侧详情；页面和标签切换不覆盖用户折叠偏好。
- 移除重复控制路径；无对应详情的表面不误显示其他功能侧栏，右侧助手/主机工具保持独立。
- 统一详情收放的 150ms 尺寸与透明度过渡；收起时立即隔离交互，支持减少动态效果与窄布局。
- 保留现有本机折叠存储键、各模块宽度与选择状态，不卸载有状态的编辑正文。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `workspace-layout`：增加统一左侧详情开关、功能归属与跨功能保留折叠状态的约定。

## Impact

前端 ActivityBar、App、各功能导航容器、编辑器侧栏和现有侧栏快捷键；使用既有语义样式与图标系统。无 Rust、远端授权、数据库或凭据契约变更。
