# SFTP 双栏工作台

## Purpose

服务器在左、本机在右，独立浏览、编辑与有界批次传输。

本文记录 2026-11-21 工作区已有行为约定；不表示所有平台或真实服务已验收。

## Requirements

### Requirement: 浏览和路径确认

系统 SHALL 两栏独立保存导航与排序，目录在前并自然排序；地址草稿与已确认目录分离，仅后端成功返回的规范路径更新列表；远端路径按 SFTP 规则、本机兼容 Windows 盘符/UNC/file URL，不依赖 C:folder 的进程目录语义。

#### Scenario: 错误路径导航

- **WHEN** 用户提交不存在或拒绝访问的目录
- **THEN** 不把失败地址当作真实目录；还原已确认路径并保护期间新输入草稿。

### Requirement: 递归搜索与选择

系统 SHALL 默认筛选当前目录，递归模式按文件名/相对路径模糊匹配，300ms 防抖、不跟随符号链接目录；限制 2000 目录、100000 条目、2000 结果，改变上下文取消旧请求；选择只包含当前可见项目。

#### Scenario: 搜索达到上限

- **WHEN** 递归匹配达到任一限制
- **THEN** 显示缩小范围提示，不继续无界扫描，不用远端 shell 或搜索内容代替目录接口。

### Requirement: 传输与冲突

系统 SHALL 下载到右侧当前目录、上传到左侧；跨栏拖拽与原生外部拖放明确区分，取消/失焦/无效落点不传输；开始前读取冲突并选择覆盖/跳过/取消，批次串行、单项失败继续，沿用 operation ID 进度与取消。

#### Scenario: 目标已有同名目录

- **WHEN** 用户选择跳过该顶层项目
- **THEN** 整个同名顶层项目不传输，不隐式递归覆盖其中内容。

### Requirement: 编辑及范围限制

系统 SHALL 双栏编辑器保持独立未保存内容和 Monaco 标识，编辑目标及父目录先保存关闭后才能改名/删除；当前批次不是持久化后台调度器，不提供暂停/续传/追加/失败重试/同步/收藏；文件内容仍受原大小和格式限制。

#### Scenario: 编辑文件后返回列表

- **WHEN** 用户从编辑区切回该栏文件列表再进入
- **THEN** 保留未保存内容，不静默丢弃或跨实例串写。
